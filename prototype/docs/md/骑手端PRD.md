## 业务设定

### 一句话

骑手要么自己向运营商买包月/次卡，要么作为渠道成员用人天额度换电；同一运营商下任意站点可购可换，**不绑主站点**。

### 两种用户

| | 个人套餐用户 | 渠道成员（人天池） |
|--|--------------|-------------------|
| 权益从哪来 | 向运营商购买包月 / 次卡 | 渠道商分配的人天额度 |
| 购买入口 | 「服务购买」「购买套餐」 | 无主套餐自购 |
| 零额度时 | — | 不可换电，持电池仅可还电 |

阅读建议：先走完个人主线与人天主线，再查附录页面规格与演示身份。

### 信息架构

底部三个 Tab：

| Tab | 核心能力 |
|-----|----------|
| 首页 | 站点地图、定位、扫一扫换电 |
| 订单 | 换电订单、服务购买、退租/押金 |
| 我的 | 登录、服务状态卡、常用功能、设置 |

原型为**平铺流程图**（信息架构三 Tab + 个人套餐 P01–P09 + 人天池 C01–C08 横向箭头串联 + 个人/渠道/二期补充场景网格），**非可交互**单页演示。

定价维度为「运营商 × 城市 × 套餐规格」；站点覆盖价已废弃。详见定价专文。

### 主线一：个人套餐

典型路径：登录 → 实名 → 确定服务运营商 → 购买套餐（含免押或交押金，同一笔支付）→ 首次领电池 → 日常换电 → 续费 → 必要时冻结/解冻 → 退款/退租/完结。

| 步骤 | 用户做什么 | 成功后怎样 | 常见拦阻 |
|------|------------|------------|----------|
| 登录授权 | 微信一键登录并勾选协议 | 已登录 | 未勾选协议 |
| 实名认证 | 提交姓名、身份证号、身份证正反面照片 | 已实名 / 未实名 / 未通过 | 格式或 OCR 失败可重试；未通过由平台/运营商人工审核 |
| 确定服务运营商 | 扫柜 / 会话 / 定位；多家时弹选择 | 已选定运营商 | 拒定位、附近无站；多家见补充场景 |
| 购买套餐 | 选通用套餐 + 新人价（仅直购首购）+ 免二选一（支付分免押 / 实缴） | 个人套餐服务中，押金已办结 | 支付失败；未选押金；未勾协议 |
| 首次领取电池 | 扫码领取（非换电） | 已持电池 | 跨网关闭等门禁 |
| 日常换电 | 扫码 → 校验 → 四步柜门 | 产生换电订单，次数 +1 | 超时、无空电、跨网拦截 |
| 续费 | 在原运营商续费，不重新定位；按**正式零售价**（不适用渠道专享价） | 新套餐单 | 同购买支付失败 |
| 冻结与解冻 | 须先还电；满足条件即时生效；解冻后顺延并待领电池 | 已冻结 ↔ 待领电 | 仍持电池不可冻 |
| 退款/退租/完结 | 冷静期或中途退款；须还电 | 服务终止；押金按规则 | 超冷静期；仍持电池 |

个人权限：可购套餐、续费、冻结/解冻、冷静期/中途退款、退租退押。**持电池时禁止**冻结、退款、退租。

通用套餐规格：7 天 / 30 天 / 90 天 / 10 次 / 30 次等；1 天畅换、单次为个人可选（**不是**渠道兜底）。计时口径见 [个人套餐定价与退款.md](./个人套餐定价与退款.md)。已有有效套餐时续费锁定原运营商，见 [用户-运营商归属模型.md](./用户-运营商归属模型.md)。

服务状态（白话）：未登录 · 未实名 · 未开通 · 服务中 · 待领取电池 · 已冻结 · 退款申请中 · 退租中 · 已完结 · 套餐过期 · 次数耗尽。

### 主线二：渠道人天

**后台先发生、用户端不演示**：渠道向运营商采购人天 → 登记骑手入团队 → 分配人天 → 权益到账。规则见 [天数池.md](./天数池.md)。

| 步骤 | 用户看到 / 做什么 | 成功后怎样 | 异常 |
|------|-------------------|------------|------|
| 登录授权 | 同个人登录；不引导购主套餐 | 进入渠道成员态 | 协议未勾选 |
| 权益到账 | 只读：渠道、团队、剩余人天 | 服务卡 = 渠道人天 | 待分配空态 |
| 今日预占 | 展示今日已预占 / 已确认 / 失败 | 已预占可换电 | → 额度异常 |
| 首次领取电池 | 未办押金则先免押/缴押；再扫码领取 | 押金已办结 + 持电池 | 未办押金；门禁失败 |
| 日常换电与确认消耗 | 换电成功；结果页「今日已确认 · 不重复扣」 | 换电单 + 确认消耗 | 跨网规则同个人 |
| 额度异常 · 仅可还电 | 展示原因；**禁止换电**；持电池仅可还电；联系渠道续配 | 还电后仍不可用直至续配 | — |
| 离职 / 移除 | 渠道侧触发；用户端只读 | 服务终止；持电池仅可还电 | — |
| 还电与回池完结 | 还电入柜；剩余人天回池（不向骑手退款） | 服务完结 | — |

渠道成员：**没有**主套餐购买入口；不可冻结、冷静期退款、中途退款；与个人套餐互斥。换电前校验见 [渠道骑手可换电校验.md](./渠道骑手可换电校验.md)。**无自费兜底**（零额度不能自己掏钱买一天换电）。

### 关键页面（业务要点）

**首页**：附近站点、定位、扫一扫。附近无站 / 拒定位要有提示。个人与人天地图交互相同；专属站白名单为二期。

**扫码换电 / 领电池**：展示柜机、站点、流程步骤、电池编号与电量等；成功页**不**向用户展示跨网三元组与设备服务费（后台记账）。模式含领取电池 / 换电 / 仅还电。失败：未登录、未开通、已冻结、预占失败、跨网关闭、柜机异常等。个人走套餐校验，人天走渠道权益校验；失败则仅可还电。

**我的 · 服务状态卡**：展示权益类型、套餐名或人天剩余、今日资格、是否持电池、主按钮。空态：未开通 / 待分配。个人主按钮多为服务购买 / 续费 / 解冻；人天多为扫码还电 / 联系渠道续配。

**服务购买**：收款运营商、套餐规格与价格、有效期口径、新人标、协议、押金方式（免押/实缴）、套餐费 + 押金 = 应付合计。无法解析运营商时阻断。人天主线不进本页。

**订单三 Tab**：换电 / 服务购买 / 退租。人天通常无自购套餐单、无退租主路径；离职还电可记还电类。空态：「暂无…记录」。

### 补充场景（默认折叠）

个人侧：定位拒绝、附近无站、多运营商选择、支付失败、柜机超时/无空电、跨网案例、冷静期退款、中途完结退款。  
人天侧：预占失败/零额度仅还电、持电池仍确认消耗、离职持电池仅还电、个人与渠道互斥说明。  
二期：设备租赁白名单、骑士卡链接（**首笔**专享价 / 续费与再次购卡正式价）、渠道专属站等——保留演示，不计入一期主线必测。

### 与后台怎么对齐（白话）

| 用户端 | 后台大致对应 |
|--------|----------------|
| 个人套餐权益 | 运营商套餐购买订单 |
| 渠道人天权益 | 渠道额度池 |
| 换电单 | 订单与服务 → 换电订单（含用户/柜机/电池分属） |
| 换电被拦 | 关跨网、信用停跨网等 |
| 零额度被拦 | 权益校验失败原因 |

### 关键埋点（产品）

对齐 [最小埋点清单.md](./最小埋点清单.md)：购套餐支付成功、人天确认消耗 / 预占失败曝光、跨网设备费、新人价消耗。原型阶段用演示结果页与订单写入代替真实上报。

### 非本期

真实微信登录 / 支付 / 地图 / 物联网；推送与消息中心；多语言；设备租赁 / 骑士卡 / 平台营销升为一期主线；骑手端演示渠道采购→登记→分配全流程。
