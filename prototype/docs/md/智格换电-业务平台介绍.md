> **用途**：业务推广 / 招商 / 合作洽谈对外口径

## 一、一句话

**智格换电**是面向外卖、快递等即时配送骑手的**换电服务平台**：我们建设物联网与骑手端，连接**运营商、渠道商、设备资金方**，把「取电—换电—还电—计费—清分」做成可规模化经营的数字化生意。

---

## 二、我们解决什么问题

| 痛点 | 传统做法 | 智格换电 |
|------|----------|----------|
| 骑手补能慢、排队充电 | 自备电池 / 站点慢充 | 柜机扫码换电，分钟级补能 |
| 谁收款、怎么分账说不清 | 线下对账、纠纷多 | 骑手付款进**运营商**，平台按约 **1%** 技术服务费实时清分 |
| 渠道批量服务难管 | Excel 发额度、难核销 | 人天池 / 推广链接 / 白名单 / 激活码，四种模式可选 |
| 设备投入重 | 一次性买断压力大 | 可对接设备租赁资金方，轻资产扩网点 |
| 跨站换电难结算 | 口头约定、对不上 | 跨网设备服务费平台代收代付、日清 |

**核心主张**：平台做「技术 + 规则 + 清分」；运营商做「网点 + 经营 + 服务」；渠道做「运力组织与获客」——权责清晰，才能一起扩规模。

## 四、平台核心能力

### 1. 骑手换电体验

- 小程序登录、实名、附近柜机换电还电  
- 个人套餐（包月/次卡等）与渠道权益并存  
- 押金：实付或芝麻信用免押；**押金付给运营商**，退押规则清晰  
- 套餐结束后仍持电：按日**电池占用费**（先付后还），减少资产沉淀  

### 2. 运营商经营中台

- 个人套餐定价、押金与退款设置、换电范围  
- 订单与服务：套餐单、换电单、用户押金、退款、**逾期管理**  
- 我的流水：资金实收、清分明细、提现（须平台审核）  
- 站点与设备台账；可对接站点合伙人分润（按合作进度）  

### 3. 渠道增长引擎（四模式）

| 模式 | 适合谁 | 怎么玩 |
|------|--------|--------|
| **人天池** | 外卖站点、车队集中采购 | 向运营商批发人天，登记骑手分配额度，按消耗结算 |
| **链接类** | 需要推广分销的渠道 | 专属链接/码获客购卡，佣金即时分账或线下结 |
| **设备租赁** | 带站带设备的合作方 | 白名单骑手换电，月租与付费套餐可组合 |
| **激活码** | 线下批发开通 | 码核销开通权益，适合批量铺货 |

### 4. 资金与清分（架构清晰）

- **架构 B**：骑手套餐等 C 端款项进入**运营商收款商户**，支付成功后平台技术服务费与运营商净额**实时清分**  
- 不做「服务做完再慢慢分」的糊涂账，对账更简单  
- 跨运营商换电：跨网柜机/电池服务费经平台代收代付、日清  

### 5. 合规与协议体系（可对外说明）

用户注册：平台用户协议、隐私政策、数字证书协议（平台主体：杭州鲸瑜贸易有限公司）  
购套餐：用户—运营商—平台**三方服务协议**  
办押：电池押金协议（**运营商收款**）  
注销：账号注销协议

## 五、合作价值主张（按对象说）

### 对运营商

- **收款在自己**：经营现金流清晰，平台抽成透明（约 1%）  
- **渠道可复制**：一套后台签多种渠道，不必自建系统  
- **资产可周转**：逾期占用费 + 催还能力，降低电池压占  
- **可轻可重**：自有设备或租赁设备都能管  

### 对渠道商

- **模式自选**：人天采购或链接分销，匹配你的组织方式  
- **消耗可核对**：额度、核销、佣金明细在线可查  
- **骑手好落地**：成员领电、换电路径统一，减少地推扯皮  

### 对资金方 / 设备商

- **承租主体在平台体系内**：运营商须平台绑定，降低乱租风险  
- **协议与租金可跟进**：适合规模化投放柜机与电池  

### 对骑手（口碑与留存）

- 换电快、规则看得见：套餐、押金、占用费、退款口径一致  
- 信用好可免押，降低开工门槛

## 七、为什么是「平台」而不是「单运营商 App」

| | 单运营商系统 | 智格换电平台 |
|--|--------------|--------------|
| 跨城/跨商换电 | 难互通 | 跨网结算内生 |
| 渠道批发 | 各做各的 | 统一签约与四种模式 |
| 设备融资 | 难标准化 | 租赁公司可平台绑定 |
| 用户协议与清分 | 主体混乱 | 平台账户 + 运营商履约收款分层 |

一句话：**平台负责把规则和资金路径做标准，运营商负责把本地生意做大。**
