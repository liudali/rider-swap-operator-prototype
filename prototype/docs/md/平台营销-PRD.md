# 平台营销 · 产品需求说明

> **这是什么**：平台向自愿参与的运营商投放**立减券**获客；用户购套餐时须锁定运营商，实付款进该运营商收款账户；平台另收营销服务费（与 1% 技术服务费分开）。整块属**二期**。  
> **依据/关联**：[渠道结算模式规则.md](./渠道结算模式规则.md) · [合作模式与分账.md](./合作模式与分账.md) · 决策索引见文末附录

## 业务设定

### 一句话

平台发活动链接（必须指定参与运营商）→ 用户领立减券、按原价减券实付 → 钱进锁定运营商 → 平台拿 1% 技术服务费 + 协议约定的营销服务费；**平台不代收用户套餐款**。

### 交付范围

二期：原型可浏览，一期不交付。规则仍作为二期规格有效。

### 和「渠道分销」差在哪

| | 渠道分销（骑士卡类） | 平台营销 |
|--|---------------------|----------|
| 优惠 | 渠道专享价 | 立减券（原价 − 券 = 实付） |
| 收款 | 运营商收款账户 | 同样：锁定运营商收款 |
| 链接 | 可带运营商 | **必须**带参与活动的运营商 |
| 运营商 | 通常签一家 | 多家自愿报名，各有投放链 |
| 平台收入 | 1% 技术服务费 | 1% + **营销服务费（协议月结）** |
| 用户款过桥 | 无 | **无**（已废止平台代收再拨付） |

不新增第五种渠道结算模式；与渠道分销并行。

### 端到端（白话）

1. 平台建活动：定各套餐原价与立减面额。  
2. 与自愿参与的运营商签约（写明营销服务费/单、券成本由谁承担）。  
3. 生成推广链接（带活动、套餐、锁定运营商）。  
4. 用户点击后 24 小时内按「最后一次触达」归因。  
5. 收银台展示：原价、立减、实付；收款方 = 锁定运营商。  
6. 支付成功 → 套餐立刻服务中；用户归属该运营商。  
7. 1% 按**实付**走支付分账；营销服务费记协议应付（不从用户款里截留）。

### 钱怎么算（白话）

| 时点 | 动作 |
|------|------|
| 展示 | 原价、立减、实付 = 原价 − 立减 |
| 支付成功 | 运营商实收 = 实付；平台 1% 按实付 × 该运营商 C 端费率 |
| 支付成功 | 券核销记账 = 立减面额（默认是**运营商让利**，不是平台补贴） |
| 协议结算 | 按签约「每单营销服务费」应付平台 |

签约文案须明示：券成本默认由锁定运营商承担。

### 谁用什么菜单

| 角色 | 菜单位置 | 能力 |
|------|----------|------|
| 平台管理员 | 平台营销（二期） | 活动/券、运营商签约、带运营商的链接、成交、对账 |
| 运营商 | 渠道管理 → 平台营销（二期） | 确认参与、看本司成交与月对账（营销费应付） |
| 骑手 | 品牌小程序（二期） | 领券立减；购时看见锁定运营商；付完即服务 |

### 归因

24 小时最后触达：平台链赢则享受该活动×该运营商的立减；窗口内被骑士卡链接盖过则走渠道专享价。

### 退款

服务中退款：运营商按实付原路退；1% 与营销服务费按规定冲正。没有「激活前平台退款」路径（已无平台代收）。

### 空态与错误

| 场景 | 处理 |
|------|------|
| 链接缺运营商或未签约 | 拦截：「请选择参与活动的服务商」 |
| 券已核销 / 活动停用 | 恢复原价或提示活动结束 |
| 对账无数据 | 「本月无平台营销成交」 |

### 已确认的产品结论（白话）

1. 营销服务费与 1% 技术服务费分开计提、分开展示。  
2. 用户款进锁定运营商，平台不代收过桥。  
3. 购买时锁定运营商（链接须带，或下单前强制选）。  
4. 运营商自愿报名。  
5. 渠道归因 24 小时最后触达。  
6. 优惠以活动级立减券面额配置为主。

## 实现附录（开发用）

> 业务读者可跳过。

### A. 端到端伪流程

```text
平台创建 Campaign（SKU 原价 + 立减券面额）
  → 与 opt-in 运营商签约（营销服务费/单）
  → 生成链接（ch=PLATFORM + campaign + sku + op=已签约OP）
  → 用户点击（24h 归因，last touch）
  → 收银台：list_price / coupon_amount / paid；收款方=锁定运营商
  → 支付成功 → userOwner=op；套餐服务中
  → 1% 按实付分账；marketing_service_fee 记协议应付
```

### B. 资金字段

| 时点 | 字段 / 金额 |
|------|-------------|
| 展示 | `list_price` / `coupon_amount` / `paid = list − coupon` |
| 支付成功 | 运营商实收 `paid`；`platform_fee = paid × C端费率` |
| 券核销 | `coupon_amount`（运营商让利） |
| 协议 | `marketing_service_fee` / 单 |

### C. 核心对象

**Campaign**：`sku_prices[]` 含 `officialPrice`、`couponAmount`、`payPrice = official − coupon`。

**链接**：`link_url` 必须含 `op=`；`op` 须为该活动×SKU 下协议已启用的运营商。

**订单**

| 字段 | 说明 |
|------|------|
| `payment_architecture` | `operator_collect` |
| `coupon_id` / `coupon_amount` | 核销券 |
| `locked_operator_id` | 支付前锁定，= `userOwner` |
| `paid_price` | 实付 |
| `platform_fee` | 1% |
| `marketing_service_fee` | 应付平台营销费 |
| **无** | `activation_status=pending`、平台拨付用户款 |

### D. 状态机

支付成功 → 服务中（`userOwner` 已锁定）。退款：运营商原路退 + 券/营销费冲正。
