## 第一条 定义

1. **用户**：完成智格换电注册、实名（如需）并使用服务的自然人。  
2. **平台方**：提供物联网、客户端、规则引擎、清分技术与平台治理的技术服务方。  
3. **运营商**：在智格换电体系内向用户提供换电履约、柜机与电池运营、套餐定价与收款的经营主体。您购买个人套餐或办理押金时，页面将展示**实际签约/收款运营商**。  
4. **换电服务**：用户在约定柜机取用、更换、归还平台体系内电池的服务；用户仅取得电池**使用权**，不取得所有权。  
5. **个人套餐**：用户向运营商支付费用开通的按天畅换或按次卡等权益。  
6. **渠道权益**：用户通过人天池、推广链接、设备租赁白名单、激活码等渠道方式获得的换电权益（具体以页面展示为准）。  
7. **押金**：为约束还电、损坏等风险，用户向运营商实付的保证金，或经信用评估获得的免押额度。  
8. **电池占用费**：个人套餐权益结束后仍持有电池期间，按日向用户计收的费用（产品展示名；非「罚款」）。

## 第五条 套餐、费用与支付

1. **计费展示**：套餐名称、有效期/次数、价格、开通方式（购买立即生效或首次领电生效）、新人价（如有）以购买页及《购买须知》为准。  
2. **支付**：您通过微信、支付宝等第三方支付完成付款时，还须遵守该支付机构规则。  
3. **收款主体**：个人套餐费、实付押金、电池占用费由**展示的运营商**收取；平台方按规则参与技术服务费清分。发票由实际收款/服务方开具（以页面或客服说明为准）。  
4. **套餐期内停用**：除本协议及《购买须知》列明的可退情形外，已开通权益不因您主动停用不使用而自动全额退款。  
5. **可退情形（个人套餐，摘要）**：  
   - **冷静期**（适用于按天类套餐，自开通服务起算，演示/一期口径为 **3 个自然日**）：按剩余天数比例退还套餐费，规则以退款设置与页面为准；冷静期内符合条件的可自动按公式退，无需另行协商改价。  
   - **中途完结**：冷静期结束后，可按剩余天数等规则申请退套餐费（具体公式与审核方式以运营商「退款设置」及退款管理结果为准）。  
   - **按次套餐（次卡/单次）**：生效后原则上不可退套餐费；待激活且未领电等情形按页面规则处理。  
   - **待激活未领电**：符合规则时可全额退套餐费（未使用）。  
6. 渠道人天、白名单、激活码等用户，套餐费与退款规则以渠道合约及页面说明为准，**不适用**上述个人套餐冷静期全文，除非页面另行明示。

## 第六条 押金与信用免押

1. **何时办理**：  
   - 购买个人套餐时，通常与套餐**同一笔支付**完成实缴押金或信用免押；  
   - 渠道人天等用户，一般在**首次领取电池前**办结押金或免押，未办结不得取电。  
2. **信用免押**：以平台统一公布的芝麻信用等门槛为准（一期演示口径：**芝麻信用 ≥ 500**）；达标可免实付押金，记为信用免押。本期不以微信支付分为免押条件。  
3. **实付押金**：金额由运营商在其押金设置中配置；押金**不参与**平台技术服务费抽成与站点合伙人分润。  
4. **退押**：  
   - 前提：电池**已归还**，且存在实付在押押金；  
   - **个人套餐逾期未还电期间不得申请退押**；  
   - 退押路径为退款管理中的「押金退还」，自动或手动以运营商设置为准；  
   - 仅退押金**不当然导致**套餐中途完结。  
5. **押金与占用费**：**押金不得抵扣电池占用费**；占用费须另行支付（或经运营商减免）。还电并结清相应费用后，押金按本条退还规则处理。

## 第八条 逾期与电池占用费（个人套餐）

1. **进入逾期**：同时满足：（1）当前仍持有电池；（2）个人套餐已到期或次数耗尽（或其他权益已结束且规则认定须还电）。  
2. **计费**：  
   - 占用费 = 逾期天数 × 运营商配置的日费；  
   - 逾期天数按「不足一天按一天」计算；  
   - **一期暂不设占用费封顶**；日费以运营商「逾期设置」及页面展示为准。  
3. **先付后还**：应付占用费大于 0 且未支付前，**不得进入还电流程**；支付成功或运营商将应付调整为 0（减免）后，方可还电。  
4. **减免**：运营商可在系统计费范围内调低应付（含调至 0），并记录原因；调至 0 视为占用费已结清，可还电。  
5. **资金归属**：占用费全额归运营商，**不计入**平台 1% 抽成、不参与站点分润（一期口径）。  
6. **状态区分**：电池是否归还与占用费是否支付为两个独立状态；已支付占用费但未还电的，仍应尽快还电，不视为服务完结。  
7. **催还与协助**：逾期后平台或运营商可通过站内信、短信、电话或委托第三方进行催还提醒；提供必要信息时应遵循合法、正当、必要原则。  
8. 本条所称「电池占用费」为产品与账单用语；如其他文本出现「违约金」等表述，**计费与执行以本条及页面展示为准**，且不得与「从押金中自动划扣占用费」「固定封顶金额」等已废止口径混用。

## 第九条 渠道权益用户的特别约定

1. **人天池用户**：个人可用人天为 0 仍持电时，按规则从所属渠道的额度池扣减人天（不足一天按一天），**不向骑手收取现金占用费**；骑手端展示「无需支付占用费」。您仍应及时还电。  
2. **链接类用户**：购卡与佣金、退款冲正按购买时链接规则与运营商结算规则执行。  
3. **设备租赁白名单 / 激活码**：准入与是否购套餐以渠道与页面为准；停服等情形下仍应允许还电（如适用）。  
4. 渠道权益不影响您对电池的保管与合法使用义务。
