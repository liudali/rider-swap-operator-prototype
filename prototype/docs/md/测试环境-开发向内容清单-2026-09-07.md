# 换电后台 · 不适合向使用者展示的开发向内容

> **范围**：2026-09-07 测试环境实走，「演示员-平台 / 演示员-运营商 / 渠道商-人天池 / 渠道商-链接类」各页  
> **使用者**：平台运营、运营商运营、渠道商（不是研发）  
> **原则**：进度、接口、内部编码、调试单位，一律不要出现在正式工作台。未完成能力 = **隐藏入口或空态业务话术**，不要写「未接入 / 待开发 / Mock」。

统一改法（所有页共用）：

| 现网说法 | 给使用者 |
|----------|----------|
| 待开发 / Mock 数据 / 真实接口已接入 | 侧栏隐藏；或空态「本能力尚未开放」 |
| 未接入 / 暂未接入 / 功能暂未接入 | 列、筛选项直接去掉 |
| IoT 接口接入后补充 / 后端已返回 | 「在线状态暂无」 |
| 单位：分、型号 ID、CMB_AGGREGATE、MONTHLY_30D | 元、型号名、招商银行聚合、包月30天 |
| sellerOperator / userOwner / U·C·B | 售卖运营商 / 用户所属运营商 / 用户·柜机·电池运营商 |

## 可保留（不是开发向）

- 协议同意记录的版本不可改、留痕只追加 → 合规需要，用「版本指纹」而非 SHA-256 即可。
- 设备 **SN**、订单号、商户号脱敏 → 业务核对需要。
- 「C 端 / B 端」若培训过可留；否则改为「个人套餐 / 渠道人天」。
- 统价「当前生效 / 待生效」是业务概念，保留。

---

## 给研发的最小改法

1. 侧栏去掉所有「待开发」；未上线路由对演示员不可见。  
2. 全局禁止文案：`未接入` `暂未接入` `功能暂未接入` `Mock` `真实接口已接入` `IoT 接口` `后端`。  
3. 字典化展示：型号名、通道名、SKU 名、渠道商名；禁止表头「型号 ID」、单元格数字 ID。  
4. 「单位：分」从列表删除（BUG-P-001）。  
5. 说明弹窗禁止英文字段名（sellerOperator、userOwner、channelName）。
