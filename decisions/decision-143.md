# 决策卡片 #143
- **日期**：2026-09-15 | **阶段**：MVP

## 决策问题
个人占用费何时收？运营商能否改价？钱给谁、记在哪本账？

## 调用的大师视角
- 俞军：先付钱再还电，替换成本发生在用户最想结束占用的瞬间，收款才成立。
- 乔布斯：只拦个人现金这一闸；人天仍直接还电；减免只做「改应付 + 日志」，不加审批流。
- Cagan：覆盖 decision-142「还电不拦」——电池优先改为「钱先结清」，资产回收依赖付费或减免。

## 核心判断
1. **个人套餐逾期须先付清占用费，才能进入还电流程**（扫码/开柜）。人天池占用不收现金，仍可直接还电。  
2. **运营商可改本单应付**（含改为 0）：0 ≤ 改后应付 ≤ 系统计费；改为 0 视为已结清，直接还电。每次改价写减免日志（时间、操作人、原金额、新金额、原因）。  
3. **占用费全额进运营商**，不抽平台 1%、不切站点合伙人、不进清分明细。  
4. **资金实收增加「逾期占用费」模块**（类型=电池占用费）。

## 反方最强论据
骑手没钱或不愿付时，电池更难回来，丢失率可能高于「先还电再补缴」。缓解：运营可减免为 0；客服可改价。失效：丢失率因门禁明显上升。

## Non-goals
按日从押金划账、占用费分润、减免审批流、人天向骑手收现金、封顶。

## 下一步验证
个人未付清无法模拟还电；减免为 0 可还电且有日志；资金实收能筛出电池占用费且清分明细无对应行。

## 知识沉淀
收款闸门放在还电入口，而不是还电成功之后。减免是改应付，不是事后冲正。不分润的收入单独进资金实收，不进清分账。
