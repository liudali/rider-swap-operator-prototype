# 决策卡片 #121
- **日期**：2026-08-31 | **阶段**：MVP

## 决策问题
运营商电柜到货后可能暂不投放。站点能不能空着？空站的柜怎么第一次上站、怎么从站上撤下来？

## 调用的大师视角
- 乔布斯：不另开「入库仓/待投放池」页面；空站就是站点字段为空，「移柜」一个动作覆盖投放、改站、卸站。
- 俞军：新体验 = 柜机能合法待仓，不必虚构一个站点；替换成本低（沿用移柜弹窗）。

## 核心判断
**站点可空是合法状态。展示文案统一为「未分配站点」。移柜对所有自有柜开放。**

| 项 | 规则 |
|----|------|
| 空站 | `site = 未分配站点`（含导入初始、卸站后）；列表/详情/筛选可见 |
| 移柜 · 未分配 | 目标 = 在营站点 → 首次投放；同步投放地址与城市 |
| 移柜 · 已上站 | 目标 = 其他在营站，或「未分配站点（暂不投放）」卸站；卸站清空投放地址 |
| 编辑 | 所属站点只读；改站点只能走移柜 |
| 电池 | 仍不绑站点；移柜不迁电池 |
| 与 120 | 卸站后平台「改归属」不再拦截；已上站仍拦截 |

## 反方最强论据
空站柜应强制建「中心仓」站点，避免空值。拒绝：仓不是经营点，硬建会污染站点经营指标和合伙人分润。

## 失效条件
财务按站点计提场租/电费且空站必须进虚拟仓科目 → 再引入系统仓站点，而不是禁止空值。

## Non-goals
- 不新建「待投放」列表或仓库实体
- 不做批量移柜（[待确认] 若一次到货几十台再开）
- 电池不绑站点

## 下一步验证
- 运营商 → 我的设备 → 换电柜：CAB-IMP-01 站点=未分配站点，可移柜投放
- CAB-22018 移柜可选「未分配站点（暂不投放）」；卸站后投放地址为空
- 筛选「未分配站点」只出未上站柜
- 站点经营统计不含「未分配站点」假站点

## 知识沉淀
设备归属（运营商）和投放位置（站点）要拆开；空站点是「未投放」，不是数据错误。
