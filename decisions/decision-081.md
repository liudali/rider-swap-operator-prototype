# 决策卡片 #081 · 平台设备管理：电柜 / 电池分 Tab + 电池 SOH · 当前归属

| 项 | 内容 |
|----|------|
| 日期 | 2026-07-27 |
| 阶段 | 发布前 |
| 结论 | **已落地**：设备管理二级 **电柜 / 电池**；电池列增加 **SOH**、**当前归属**（电柜 / 用户 / 柜外）；电柜「在线状态」独立，不再与 SOC 混列 |

## 决策问题

全平台设备台账柜/电池混表，且「状态」列对柜显示在线、对电池显示 SOC（decision-079 P1）。

## 调用的大师视角

- **唐·诺曼**：类型分 Tab 后，列语义可专属化。
- **乔布斯**：去掉混表「类型」列；电柜只保留在线态。

## 已确认规则

### 信息架构

| 二级 Tab | 列表字段 |
|----------|----------|
| **电柜** | SN、规格、归属运营商、城市、站点、**在线状态**、归属日、导入日期 |
| **电池** | SN、规格、归属运营商、城市、站点、**SOC**、**SOH**、**当前位置**、归属日、导入日期 |

### 当前归属（平台三档）

| 取值 | 含义 | 副行 |
|------|------|------|
| **电柜** | 在任意柜机格口（含跨运营商柜） | 柜机 SN |
| **用户** | 骑手持有 | 持有人 |
| **柜外** | 柜外充电 / 待入柜 / 资方库存等 | 原位置文案（若有） |

> 与运营商「我的设备·电池」四档位置（自有电柜 / 其他运营商电柜 / 柜外 / 柜外-用户）**粒度不同**，平台侧合并柜内两档、用户单独成档。

### 兼容

- 旧 `platformDeviceTab=ledger` → `cabinet`
- 旧 `import` → 打开批量导入弹窗 + `cabinet`
- 批量导入入口在电柜/电池 Tab 均保留

## 支持 / 反对 / 失效

- **支持**：消混列；平台可扫 SOH 与物理归属。
- **反对**：侧栏多一级；与运营商四档需培训区分。
- **失效**：产品要求平台与运营商位置枚举完全一致。

## Non-goals

- 不改运营商电池四档位置。
- 不在平台电柜列表加通电态（仍在运营商换电柜页）。
