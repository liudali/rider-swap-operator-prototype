# 决策卡片 #154
- **日期**：2026-11-23 | **阶段**：发布

## 决策问题
包月（按天）套餐用户逾期后，是否允许续费继续持电？续费与占用费如何结算？

## 调用的大师视角
- 俞军：续费扣天数 = 用「少几天服务」换「免还电+免现金占用费」，对赶单骑手净价值更高，资产仍在网内服务。
- 乔布斯：包月与次卡拆成两条逾期出口——包月可续、次卡不可续，避免一套规则硬套。
- 贝佐斯逆向：三年后账本要能说清「这 N 天是占用费还是吃进新套餐天数」，二者互斥、不可双收。

## 核心判断
**包月/按天套餐逾期允许续费。** 续费成功时：逾期天数从新套餐生效天数中扣除，**不计算、不收取**电池占用费；用户可继续持电换电。次卡/单次仍按 decision-153 禁续费。

| 项 | 口径 |
|----|------|
| 适用范围 | 按天 SKU（包月 30/7/1 天等 `monthly`/`daily`）；**不含**次卡/单次 |
| 续费入口 | 逾期进行中且仍持电：可续费（同运营商、正式零售价） |
| 逾期天数 | `D = max(1, ceil((续费支付成功时刻 − 进入逾期时刻) / 24h))`（与占用费计天同口径） |
| 生效天数 | `生效天数 = SKU 标称天数 − D`；须 **≥ 1**，否则不可走续费，只能付占用费后还电 |
| 占用费 | 走续费解脱时：**应付占用费 = 0**，不生成占用费收款；与「付占用费还电」路径互斥 |
| 还电路径 | 不续费、选择还电：仍先付占用费（或减免）再还电（decision-143） |
| 押金 | 续费不重复收押；在押继续 |
| 状态 | 续费成功 → 退出逾期名单；新单服务中；可换电 |
| 次卡 | 不变：禁止续费解脱（decision-153） |

## 反方最强论据
用全价买「被扣短」的套餐，骑手觉得亏；或长期拖欠靠续费「洗」占用费。缓解：购买页明示「已逾期 D 天将从新套餐扣除、不收占用费」；`生效天数 < 1` 时关掉续费。失效：客诉集中要求按剩余天数折价——另开定价决策。

## Non-goals
- 次卡/单次逾期续费
- 占用费与扣天数同时收取
- 续费按扣除天数折价（本期按 SKU 全额计价）
- 人天池路径

## 下一步验证
- 包月逾期屏同时有「续费」「支付占用费」；次卡逾期无续费
- 续费成功后占用费为 0、可换电；生效天数 = 标称 − D
- D ≥ 标称天数时续费按钮不可用

## 知识沉淀
逾期天数只能花一次：要么换成占用费现金，要么扣进新套餐天数——不能两头收。
