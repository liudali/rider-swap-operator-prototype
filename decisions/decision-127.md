# 决策卡片 #127
- **日期**：2026-09-07 | **阶段**：MVP

## 决策问题
3 天冷静期内用户申请退款，是否仍须运营商人工审核？

## 调用的大师视角
- 乔布斯：冷静期是法定/承诺权益，金额公式已定，人工审只增加延迟与客诉。
- 张小龙：克制运营裁量；按天比例自动退，减少后台「砍一刀」空间。

## 核心判断
**冷静期内申请：系统按天数比例自动原路退套餐费（+押金按还电规则），不进人工审核队列。与套餐退款「自动/手动」开关无关。**

| 项 | 规则 |
|----|------|
| 窗口 | 开通服务起 3 个自然日（立即生效=支付日；首次领电=领电日） |
| 金额 | 套餐费 = 实付 × 剩余自然日 ÷ 总天数（四舍五入到分）；押金按还电规则 |
| 审核 | **不需人工**；申请后系统执行 |
| 与自动/手动 | 冷静期路径独立；开关只约束冷静期外的中途完结/SKU 退订 |
| 按次 | 生效后仍不适用冷静期（decision-125） |
| 超时 | 入口关闭；改走中途完结等 |

## 反方最强论据
自动退无法拦套利/异常单。拒绝：冷静期短、公式透明；异常可事后风控，不阻塞正常退。

## 失效条件
监管或合同要求冷静期必须人工确认实退额 → 恢复须审。

## Non-goals
- 不开放冷静期内改公式或运营改实退额
- 不改超过冷静期后的中途完结规则

## 下一步验证
- 退款设置：冷静期「审核方式」= 按天比例自动退、无需人工
- 切换自动/手动弹窗：不再写「冷静期始终须审」
- Mock 冷静期单可为已自动退款

## 知识沉淀
冷静期 = 承诺自动退；自动/手动 = 仅管冷静期外作业。
