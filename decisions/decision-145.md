# 决策卡片 #145
- **日期**：2026-09-16 | **阶段**：MVP

## 决策问题
逾期单要同时看清「电池还了没」和「占用费付了没」，还是继续用「进行中 / 已完结 + 待支付」混在一起？

## 调用的大师视角
- 俞军：运营追两件事——电池和钱。混成一个完结态，已付未还会被当成办完。
- 乔布斯：只加两列枚举，不加第三套 Tab。减免为 0 归入已支付，不单开「已减免」。
- 诺曼：待支付 / 已付清 / 已完结 用词不一致；电池和费用各用一对反义词。

## 核心判断
1. **电池**：未归还 / 已归还。进行中默认未归还；还电成功才已归还。  
2. **逾期费**（个人）：未支付 / 已支付。实付或减免为 0 都算已支付（副文案可标减免）。人天不收现金，展示「无需支付」。  
3. 先付后还不变：个人未支付不可还电，故**已归还 + 未支付**个人单不出现。  
4. 列表必须同时露出这两维；筛选可按电池、逾期费过滤。

## 反方最强论据
已完结 Tab 已能代表已归还，再加电池列重复。缓解：进行中会出现「已支付 + 未归还」，没有电池列会误判为结案。失效：运营仍只看 Tab 不看列。

## Non-goals
已归还且未支付的个人路径、第三种费用态「已减免」、平台逾期工作台。

## 下一步验证
个人进行中能看到未支付未归还、已支付未归还；已完结为已支付已归还；人天逾期费为无需支付。

## 知识沉淀
钱和货是两维状态，不要收成一个「完结」。
