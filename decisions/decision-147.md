# 决策卡片 #147
- **日期**：2026-10-21 | **阶段**：MVP → 发布（跨网关停补全）

## 决策问题
跨网开启后资产已混库/混持。运营商要关跨网时，如何尽量不伤骑手体验，又把运营商引导到可完成的关停？

## 调用的大师视角
- 俞军：关停价值 = 资产干净 − 骑手「还不上 / 换不了」的痛苦 − 运维对账成本。硬关瞬间替换成本爆炸，必须把「已在途」从「新跨网」拆开。
- 王慧文（双边）：关网是双边事件。只堵本网出站不够，也要给对方回收本网电池、本柜退异网电池的对等窗口，否则对方会抵制或扣押资产。
- 乔布斯：不要做多方协商审批流。两个状态就够——**关停过渡** + **已关闭仍永久只还**。

## 核心判断
**关跨网 ≠ 立刻锁死所有跨主体电池动作。正式语义改为：停止产生新的跨网换电；已在途电池用「过渡排空 + 永久只还例外」消化。**

### 状态机
`可跨网` → `关停过渡` → `已关闭`（可再开回可跨网）

### 关停过渡（默认建议 7 自然日，可配置 [待确认]）
| 动作 | 是否允许 | 说明 |
|------|----------|------|
| 本网用户去他网取电/换电 | ❌ | 立刻停止加深混持 |
| 他网用户来本网取电/换电 | ❌ | 立刻停止外来取电 |
| 任意用户「只还电」（含还异网电池、在他柜还本网电池） | ✅ | 保护骑手，加速排空 |
| 本柜内异网电池再放出给用户 | ❌ | 柜内异网只进不出（可运维取出） |
| 跨网设备服务费 | 仅对过渡期内仍发生的「只还」若产生三元组异常 → **不产生新跨网费** [假设：只还不产生 L1] | 避免关停期还被计费刺激投诉 |

### 已关闭后的永久例外（体验底线）
- **持异网电池的用户**：仍可扫码**只还电**到能物理收纳该型号的柜子（优先电池归属运营商柜；过渡期外若本柜已关跨网，仍允许「异网电池还入本柜」但标记待调拨、不可再放出）。
- **禁止**：已关闭后任何新的跨网取电/换电。
- 这样关停完成不以「全世界计数归零」为硬前置，避免无穷尾部锁死开关。

### 运营商关停向导（引导，而非吓阻）
点「关闭本网跨网」先出**预检看板**，再选「进入关停过渡」（默认），不提供一键硬关给普通运营（硬关仅平台应急 [待确认]）。

看板四类 KPI（关停完成度主指标）：
1. 本网用户持异网电池（人/块）
2. 异网用户持本网电池（人/块）
3. 本柜内存异网电池（块）
4. 本网电池在他柜（块）

完成度 = 1 − 当前存量 / 进入过渡时存量快照。到 0 或过渡期满 → 可一键切「已关闭」；期满有残留也不挡关，残留进「待回收工单」。

### 骑手触达（体验）
- 进入过渡当日：对「本网用户持异网电池」推送/站内信：请于截止日前还电；过渡期内任意可还站点可还，逾期后仍可还但站点选择变少。
- 扫码拦截文案分层：新跨网换电 →「所属运营商已停止跨网，请到本运营商站点换电」；只还 → 放行并成功页提示「已还电，跨网服务已停止，下次请在本网换电」。
- **不**因关停对骑手加惩罚性占用费；逾期占用费规则与关停正交。

### 资产回收（B 端）
- 自动生成两类工单：① 本柜异网电池待对方取回 / 平台协调；② 他柜本网电池待收回。
- 列表可导出 SN；进度与关停看板同源。
- 不在本期做跨主体调拨审批流（延续 PRD「不做跨主体调拨审批」）；以工单 + 线下物流为主。

### 与现有规则对齐
- 仍保留 **平台开关 ∧ 运营商开关**；任一侧进入关停过渡/已关闭，实际不可新跨网。
- 信用停跨网仍只限**出站新跨网**；与关停过渡可叠加（更严者生效）。
- 渠道骑手继承所属运营商关停状态（既有 4A）。

## 反方最强论据
过渡期仍允许异网电池还入本柜，会拖长柜内异网库存。缓解：还入即「待调拨不可放出」+ 工单催收；完成度看板给运营商可见压力。

## 失效条件
- 监管要求关网后零例外物理隔离，不允许任何异网电池入柜。
- 柜机固件无法区分「只还」与「换电」。

## Non-goals
- 不做运营商间在线议价/扣押保证金自动索赔
- 不做骑手端「跨网电池强制驿站自寄」C 端物流
- 不改跨网统价与日清模型（仅约定只还不计 L1 [假设]）
- 不恢复用户主绑定站

## 知识沉淀
跨网关停的产品单位是「停止新纠缠」，不是「瞬间消灭历史纠缠」。历史纠缠用只还例外 + 运维工单消化。
