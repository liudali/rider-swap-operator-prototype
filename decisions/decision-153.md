# 决策卡片 #153
- **日期**：2026-11-23 | **阶段**：发布

## 决策问题
次卡（含单次）进入个人套餐逾期后，是否允许续费/新购次卡以继续持电换电？

## 调用的大师视角
- 俞军：续费解脱净价值 = 继续持电干活 −（付占用费+还电）− 账务/客诉成本；对「次数耗尽仍持电」场景净价值为负。
- 乔布斯：逾期态只做「付占用费 → 还电」；续费留给还电后的正常购卡。
- 贝佐斯逆向：若允许耗尽次数后买卡续持电，占用费是否清零、新旧单谁背电池将长期纠缠。

## 核心判断
**次卡/单次逾期不允许续费（含新购同类型或其它个人套餐）作为持电解脱。** 须占用费结清 **且** 还电成功后，方可再购。  
**包月/按天逾期续费见 decision-154（允许续费、扣天数、不计占用费）。**

| 项 | 口径 |
|----|------|
| 适用范围 | `times` / `single`（次卡、单次）；结束原因为次数耗尽或有效期到期且仍持电 |
| 禁止 | 逾期进行中：续费、新购个人套餐、用新单「顶」旧逾期 |
| 允许 | 支付/减免占用费 → 扫码还电；还电后按正式价购卡 |
| 主按钮 | 未结清 → 支付占用费；已结清 → 扫码还电；**不出现续费** |
| 人天 | 不在本决策范围；仍可渠道续配（非个人现金续费） |

## 反方最强论据
赶单柜远、强制还电损履约。缓解：运营可减免占用费至 0；不解禁次卡续费顶逾期。失效：法务/数据证明「先续后还」显著降丢失且账可审计——须另开决策。

## Non-goals
- 改占用费公式、封顶（还电路径仍先付后还）
- 人天池现金占用费
- 包月逾期规则（由 decision-154 覆盖）

## 下一步验证
- 骑手端次卡逾期屏无「续费」；购卡入口拦截并提示先还电
- AC：次数耗尽逾期不可开通新套餐继续持电
- 与包月可续费路径对照演示不串

## 知识沉淀
次卡结束常是「次数耗尽」而非日历到期；更不能用续费假装服务未断。逾期与购卡是两段生命周期，中间必须还电。
