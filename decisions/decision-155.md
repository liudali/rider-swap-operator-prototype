# 决策卡片 #155
- **日期**：2026-11-27 | **阶段**：发布

## 决策问题
个人套餐 SKU 状态是否只需「生效 / 停用」？库存不足时如何停新售、仍允许老用户续费？

## 调用的大师视角
- 俞军：停新开 + 保续费 = 保护在服体验 − 库存透支风险；三态比「停用后口头放行续费」清晰。
- 乔布斯：状态机压成三种可讲解结果——谁都能买、只有老客续、谁都不能买。
- 贝佐斯逆向：三年后运营问「这 SKU 能不能续」必须看状态字段，不能靠客服特批。

## 核心判断
个人套餐 SKU（运营商×城市×型号×套餐）状态枚举改为三态：

| 状态 | 新购 | 续费 | 已购履约 |
|------|------|------|----------|
| **生效** | 允许（全体） | 允许 | 照常 |
| **仅允许续费** | **禁止** | 仅合格老客 | 照常 |
| **停用** | 禁止 | **禁止** | 照常至原单结束 |

**仅允许续费 · 合格老客**（须同时满足业务其它规则，如 decision-153/154）：

1. 对本 SKU 键（同运营商×城市×型号×套餐名）有进行中权益（服务中 / 已冻结 / 待激活），或  
2. 个人逾期且仍持电，且原权益对应本 SKU（包月可走 154 续费；次卡逾期仍禁续费）

| 项 | 口径 |
|----|------|
| C 端货架 | 新客 / 无资格用户：不展示「仅允许续费」「停用」SKU；合格老客续费入口可见「仅允许续费」 |
| 渠道分销新开 | 仅可关联状态=**生效** 的底价 SKU |
| 渠道可售/推广链接 | 底价离开「生效」→ 渠道套餐展示「当前不可销售」、已启用推广链接自动停用；回「生效」且曾自动联动的可恢复 |
| 价格分区 | 区价**跟随**城市底价三态；底价不可新购时区价不可新购；底价停用不可单独靠区价售卖 |
| 取价 | 新购仅「生效」；续费可用「生效」或「仅允许续费」；停用不可新开单 |
| 改状态 | 立即影响新购/续费门禁并联动渠道；不追溯已购快照与剩余履约 |
| 统一门禁函数 | `userCanBuySkuAsNew` / `userCanRenewSku` / `resolvePkgRetailPrice({forRenew})` / `channelPackageSellable` |

## 反方最强论据
「仅允许续费」仍消耗稀缺电池。缓解：库存更紧时改**停用**；或配合换电范围/站点投放。失效：自动按库存切状态——另开决策。

## Non-goals
- 按库存自动改状态
- 人天批发价三态（本卡仅个人套餐 SKU）
- 改变押金、冻结、占用费公式

## 下一步验证
- 编辑 SKU 状态下拉三选项；列表可筛
- Mock 一条「仅允许续费」；分销价新增不可选该条
- AC：新客不可买、合格老客可续、停用不可续

## 知识沉淀
停售新客与停续费是两档；库存紧用「仅允许续费」，彻底停卖用「停用」。已购履约始终不断粮。
