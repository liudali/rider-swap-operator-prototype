# 决策卡片 #123
- **日期**：2026-09-02 | **阶段**：MVP

## 决策问题
提现工单审核通过后，平台要向支付渠道发转账指令（招商银行户 → 运营商提交的卡）。申请里要不要单独带转账银行卡号？能不能转到绑定收款账户以外的卡？

## 调用的大师视角
- 乔布斯：指令缺卡号发不出去；不要另开「提现卡管理」页，申请单上把卡号填全。
- 马斯克：转出户（收款账户）和转入卡（本笔工单）是两个对象；混淆就会把招商结算户当成唯一到账卡。

## 核心判断
**每笔提现工单必须快照转账银行卡号。默认同收款账户，允许改成其他对公卡。审核通过后发转账指令，不改收款账户档案。**

| 项 | 规则 |
|----|------|
| 转出 | 「收款账户」绑定的对公卡（演示绿色出行=招商银行）；未绑定不可申请 |
| 转入 | 本笔必填：开户名称、**银行卡号**、开户银行、开户支行；联行号选填 |
| 默认 | 带出收款账户，可改 |
| 快照 | 提交后工单自带转入信息；事后改收款账户不影响在途/历史单 |
| 审核 | 平台内部工单；通过确认弹窗展示转出/转入/金额，再向支付渠道发指令 |
| 仍对公 | 校验同收款账户（8～32 位数字卡号等） |

## 反方最强论据
只打到绑定那一张卡更安全，填卡号多余。拒绝：通道指令必须有转入账号；运营也可能临时收到别的对公户。

## 失效条件
支付通道只允许提到已鉴权的绑定卡 → 转入卡改回只读，仍要在工单上展示卡号。

## Non-goals
- 不做对私卡、小额鉴权、四要素核验
- 不把转入卡写进收款账户
- 不改站点合伙人提现

- 可改成宁波银行卡号后提交；列表「转账银行卡号」列可见
- 平台提现审核：WD-260605 转入为宁波银行；通过弹窗含转出招商 / 转入卡号

## 知识沉淀
通道要的是「从哪张卡转到哪张卡」；收款账户管转出，工单管转入。
