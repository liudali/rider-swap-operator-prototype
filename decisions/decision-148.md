# 决策卡片 #148
- **日期**：2026-10-29 | **阶段**：发布

## 决策问题
运营商「渠道管理 → 链接结算」对外名称是否改为「推广结算」？筛选与字段是否对齐现网截图？

## 调用的大师视角
- 王慧文：付款方作业面已有（decision-140），改名降低与「推广链接」心智的落差，不改清分事实。
- 乔布斯：仍一个 Tab；不拆第二套台账。

## 核心判断
**运营商菜单与页头统一改称「推广结算」**；业务规则不变（decision-065/074/137/140）。

| 项 | 口径 |
|----|------|
| 菜单 | 渠道管理 → **推广结算**（原「链接结算」） |
| 渠道侧 | 仍叫 **佣金对账** |
| 页内 Tab | 月度汇总 / 订单明细 |
| 筛选 | 统计月份起止 + 渠道商 + 结算方式；查询 / 重置 |
| KPI | 统计范围、佣金毛额、退款冲正、待线下结算 |
| 月表 | 增加累计已结、剩余待结（即时=已结满；线下待结=剩余待结；已登记=已结满） |
| 文案 | 即时分账在支付时完成；本页只读；线下由运营商登记，不代表银行权威到账 |

## 反方最强论据
改名后文档检索「链接结算」会漂。缓解：决策卡与 AC 双写旧名对照。

## Non-goals
- 不改渠道「佣金对账」
- 不进运营商 APP（仍按 decision-069 排除）
- 不做真实打款
