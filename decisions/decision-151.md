# 决策卡片 #151
- **日期**：2026-11-18 | **阶段**：发布

## 决策问题
人天额度池是否按电池型号拆分？采购可选型号、换型号、扣天与平台日值如何定？

## 调用的大师视角
- 乔布斯：池与电必须同型号，避免「买的是天数、取出的是错电」。
- 俞军：多型号车队净价值 = 可按车配型 − 一池通兑错发成本 − 换型四步操作成本；净价值 > 0。
- 唐·诺曼：换型号路径必须外显为「收回→还电→再分配→再领电」，禁止静默改绑。

## 核心判断
**人天池唯一键 = 渠道 × 运营商 × 电池型号。** 批发价按型号单独设；领电/换电必须匹配该型号额度。

| 项 | 口径 |
|----|------|
| 池切分 | 同渠道同运营商可多池（如 60V、72V 各一）；续购加在对应型号池 |
| 可选型号 | **口径 A**：运营商设备台账中**有归属记录**的电池型号（含在柜 / 用户持有 / 柜外），即可开价、采购、开池 |
| 批发价 | 运营商「人天批发价」按 **渠道(含默认) × 型号** 维护；建档仍不填价（延续 decision-104） |
| 平台标准日值 | **不分型号**；B 端 1% 仍用全网统一标准人天价 |
| 分配 | 必须指定型号池；骑手同时仅一种型号可领电 |
| 换型号 | **强制四步**：①收回原型号人天 → ②归还电池 → ③分配新型号人天 → ④重新领电；未完成禁止领新型号电 |
| 确认消耗 / 逾期占用 | 从**该骑手对应型号池**扣；余额不足占用仍扣对应型号池，不向骑手收现金 |
| 余额不足预警 | 按**单池**计算：该池可用 &lt; 持有该型号额度的在职人数 × 10（沿用 10 天跑道系数） |

## 反方最强论据
多池增加采购与分配心智；缓解：列表按运营商分组、增购默认续原型号池。  
口径 A 可能让「已无在柜库存」的型号仍可买人天；缓解：运营靠持仓与站点规划，不在采购闸死库存。

## Non-goals
- 不按区县/站点拆池
- 不改个人套餐「无一单通兑」（decision-085）以外的套餐规则
