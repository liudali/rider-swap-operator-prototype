# 决策卡片 #120
- **日期**：2026-08-31 | **阶段**：MVP

## 决策问题
平台导入设备后，部分 SN 归属导错。要不要改运营商？个别和批量怎么改？已上站的能不能改？

## 调用的大师视角
- 乔布斯：只做「纠错改绑」，不做经营调拨审批。导入仍是一家运营商 + SN 列表。
- 马斯克：柜、电、用户三个归属独立；改柜不改格内电池。

## 核心判断
**平台台账可改归属（纠错）。已分配站点一律拦截，并展示该设备的站点与当前运营商。柜内电池不随柜改。原因用枚举。**

| 项 | 规则 |
|----|------|
| 入口 | 电柜 / 电池 Tab：行内「改归属」+ 勾选批量 |
| 已分配站点 | **拦截**；弹窗列出 SN、站点、当前运营商；须先卸站 |
| 电池 | 改柜不改格内电池；电池单独改。用户持有、租赁/融资同样拦截 |
| 原因 | 枚举：**导错运营商** / **分货更正** / **其他** |
| 成功后 | 更新归属运营商、归属日；导入日期不变 |
| 历史换电 | 不改写 |

## 反方最强论据
已上站的柜也想一键改过去。拒绝：那是调拨，会碰到站点权属和跨网费（PRD §8.1 不做跨主体调拨审批）。

## 失效条件
财务/监管要求换绑必须双主体签章 → 升级为调拨单，而不是放宽拦截。

## Non-goals
- 不恢复待绑定队列；导入表格不加运营商列
- 不做调拨审批、对价、物流
- 不按柜级联改电池

## 下一步验证
- 平台设备管理 → 电柜：CAB-22018 改归属被拦截，展示站点「浦东骑手驿站」+ 运营商「绿色出行」
- CAB-IMP-01 / CAB-IMP-02 可改到陆家嘴联营；格内电池（若有）归属不变
- BAT-IMP-01 可改；BAT-SH-1001（柜内有站点）拦截
- 原因下拉为三个枚举

## 知识沉淀
纠错和调拨要分成两个动作；拦截文案要带上「现在在哪、现在归谁」。
