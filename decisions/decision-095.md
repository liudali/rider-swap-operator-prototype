## 决策问题

同一换电柜混放多型号电池，用户套餐也按型号售卖时，如何设计换电隔离，避免错规取电与套利。

## 调用的大师视角

- **第一性原理（马斯克）**：换电标的是「具体规格电池 + 对应权益」，隔离点必须落在开仓决策，而不是仅展示层过滤。
- **俞军**：错规换电的替换成本极高（车辆不适配、压差风险、客诉、套餐套利）；隔离带来的摩擦远小于事故与资损。
- **乔布斯（减法）**：不做「兼容组通兑 / 用户自选仓口」；只做系统自动匹配同型号。
- **唐·诺曼**：失败时说清「本柜暂无你的套餐型号（如 48V30Ah）」，并给下一步（附近有电柜 / 还电入口）。

## 核心判断

### 1. 三层隔离（推荐）

| 层 | 做什么 | 不做什么 |
|----|--------|----------|
| 权益层 | 有效套餐/白名单 SKU 绑定 `battery_model_id`；用户当前生效权益只解析出一个 **权益型号** | 一单通兑多型号 |
| 资产层 | 每块电池 SN → 型号（平台型号字典）；持有中电池型号可查 | 无型号电池参与换电 |
| 开仓层 | 取电只开「满电且型号=权益型号」；还电只开「空仓且机械/策略允许该持有型号入柜」 | 用户手选任意满电仓 |

### 2. 换电匹配规则（日常换电）

```text
扫柜
  → 解析权益型号 M_entitled（个人套餐 / 白名单套餐等同口径）
  → 若持有电池：持有型号必须 = M_entitled（否则仅还电路径或运维介入，禁止继续取异型号）
  → 选满电候选：model = M_entitled 且 SOC≥阈值 且可出
  → 选空仓候选：可接收「当前持有型号」入柜
  → 先开空仓还电 → 再开满电仓取电
  → 无满电同型号 → 失败：本柜无可用 {型号}，引导附近柜 / 稍后重试
  → 无空仓可接收持有型号 → 失败：本柜暂无法接收你的电池，引导附近柜或联系运维
```

### 3. 柜侧能力（产品对硬件/IoT 的要求）

- **识别**：入柜/出柜以 BMS/通讯上报的型号（或 SN→云端型号）为准，云端二次校验后再允许完成订单。
- **机械**：不同外形/接口尽量物理防呆；云端隔离是底线，物理防呆是加分。
- **库存可见**：柜维度按型号统计「可换满电数 / 可还空仓数」，供地图与失败文案使用。
- **配柜策略** `[假设]`：运营商可配置柜支持型号集合；不在支持集合内的电池禁止入柜（运维补电除外）。

### 4. 关键边界

| 场景 | 处理 |
|------|------|
| 套餐型号 A，柜内仅有 B 满电 | 禁止取电；提示无 A |
| 持有 A，想取 B | 禁止；须先还 A；换型号须先还电再购/切换对应套餐 |
| 同电压不同安时（48V20 vs 48V30） | **视为不同型号**，不兼容 |
| 首领（无持有） | 只匹配满电仓型号=权益型号；不强制空仓 |
| 仅还电（额度用尽/冻结前等） | 只匹配可接收持有型号的空仓；不开满电仓 |
| 渠道人天 | 人天权益仍须落到可换型号 `[待确认：人天是否也绑型号，或继承登记时型号]`；建议与白名单 SKU 一致绑型号 |
| 跨网换电 | 设备方柜内仍按型号隔离；跨网费与型号正交，不放宽型号 |

### 5. C 端体验要点

- 购套餐：已按型号选购（decision-085）。
- 扫柜前/后：展示「你的套餐型号」与「本柜该型号可换数」。
- 失败文案示例：`本柜暂无可用的 48V30Ah 满电电池`；勿说模糊的「柜内无电池」。

## 反方最强论据

严格隔离会降低单柜利用率（A 型空仓闲着、B 型用户换不了）。  
**应对**：运营按站点需求配比各型号库存；地图展示分型号可换；不做通兑用体验掩盖缺货。

## Non-goals

- 跨型号通兑 / 「兼容组」自动升级取电  
- 用户手动选仓口  
- 柜内按型号物理分区改造作为一期必做（可选运维规范，非系统前提）

## 支持 / 反对 / 失效

| | 内容 |
|--|------|
| ✅ 支持 | 与定价唯一键一致；防套利；降低车辆不适配与安全风险 |
| ❌ 反对 | 库存碎片化；客诉「柜里明明有电却换不了」——需分型号库存解释 |
| ⚠️ 失效 | 硬件无法识别型号且无 SN 主数据；或业务强制「一柜一价通兑」 |

## 下一步验证

1. 与研发确认：开仓前云端校验点与柜端上报字段（SN/型号/SOC）。  
2. 补骑手端/验收：分型号可换数、无同型号失败码。  
3. `[待确认]` 人天池额度是否强制绑定型号（建议绑）。

## 知识沉淀

换电隔离 = **权益型号 × 持有型号 × 仓内电池型号** 三元一致；柜混放可以，**权益不能混用**。
