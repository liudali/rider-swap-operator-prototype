## 业务设定

### 一句话

用户不绑站点，同运营商内任意站可买可换；商业归属 = **售卖/收款的运营商**。购套餐前用会话上下文解析「当前服务哪家」；**支付成功**后写入正式归属。支付页禁止再切换运营商，防止串单。

与渠道、合伙人等其它角色的建立/解除见 [用户与角色关系.md](./用户与角色关系.md)。

### 三层怎么理解

| 层 | 是什么 | 何时用 |
|----|--------|--------|
| 平台身份 | 登录用户 | 全程 |
| 会话上下文 | 当前展示价、下单用的运营商 | 购套餐 / 调起支付前 |
| 商业归属 | 售卖方运营商（清分与退款主体） | 支付成功（或渠道/激活码等权益规则）写入 |

### 购套餐前：上下文怎么定（优先级从高到低）

1. **已有生效个人套餐（续费）** → 固定原套餐运营商，不弹选择。  
2. **启动参数带运营商**（渠道链接、营销链接等）→ 用链接锁定的运营商。  
3. **本会话扫了柜机码** → 用该柜所属运营商。  
4. **定位匹配**（见下）→ 自动或让用户选一家。  
5. **仍无法解析** → 阻断购套餐，引导扫柜或开启定位。

渠道成员购**渠道白名单套餐**、激活码等：收款方或规则可能不是「签约运营商 U」，见各结算模式专文；上表主要服务个人直购路径。

### 定位匹配（方案乙）

1. 需用户授权定位；拒绝则不能走定位，提示扫柜或去设置开启。  
2. 查半径 **15 km** 内、在营、**对公众开放**的站点（专属站不参与）。  
3. 按距离取最近站所属运营商为候选。  
4. **自动命中**：最近站 ≤ **5 km**，且与「次近不同运营商」距离差 ≥ **2 km**（或次近本就是同一家）。  
5. **多家接近**：Top2 不同运营商距离差 < 2 km 等 → 弹层只选**运营商名称 + 最近站距离**（不绑站点到用户档案）。  
6. **附近无站** → 阻断，提示移步换电柜扫码或切换城市。

会话缓存建议 **7 天**（或至退出登录）；用户可「重新定位」。链接与扫柜会覆盖定位结果。定位只用最近站**反推运营商**，不把站点写入用户永久档案（订单上可可选记分析用最近站）。

### 支付与归属（架构 B）

解析出售卖方 → 使用该运营商进件子商户收款 → 支付成功 → 用户商业归属 = 该售卖方。渠道标记只影响佣金统计，**不改变**归属运营商（链接分销场景）。

### 各入口

| 入口 | 上下文从哪来 |
|------|----------------|
| 我的 · 服务购买 / 宫格购套餐 | 按上表优先级解析 |
| 渠道链接 / 二维码 | 链接锁定的运营商 |
| 扫柜引导购 | 柜机所属运营商 |
| 平台营销链接（二期） | 链接必须锁定已签约运营商；支付成功归属该家，套餐即服务中 |

### 骑手端要让用户看见什么

| 场景 | 展示 |
|------|------|
| 已确定运营商 | 顶部条：当前服务运营商 · 距您最近某站与距离 |
| 多运营商重叠 | 底部选择列表（名称 + 距离） |
| 无定位 | 购前引导开定位或扫柜码 |
| 续费 | 不弹运营商选择 |

### 验收

见 [acceptance-criteria.md](./acceptance-criteria.md) 骑手端 · 运营商归属相关条目。

### 税收拆分

多法人拆单等能力已撤出；归属仍是运营商。套餐费按设备/场地/电费等拆分的讨论见 [税收-待讨论.md](./税收-待讨论.md)，不影响本归属模型。

## 实现附录（开发用）

> 业务读者可跳过。

### A. 字段对照

| 业务说法 | 实现名 |
|----------|--------|
| 会话运营商 | context_operator_id |
| 来源 | context_source：active_pkg / launch / scan / geo_auto / geo_manual |
| 售卖方 / 归属 | seller_operator_id / userOwner |
| 子商户 | sub_mch_id |
| 渠道统计 | channel_id / link_code（不改 userOwner） |

无 home_site_id。可选 PackageOrder.nearest_site_id_at_purchase。

### B. 建议接口

`POST /api/v1/context/resolve-operator`：定位/启动参数解析；可返回 need_user_pick + candidates。  
`POST /api/v1/context/confirm-operator`：用户手动选择后写入会话。

### C. 平台营销路径 D

经平台营销购套餐须有效 op=；payment 成功 userOwner=锁定 OP；无待激活。详见 [平台营销-PRD.md](./平台营销-PRD.md)。

### D. 决策索引

不绑站点 · 定位方案乙 · 架构 B 付款定归属 · 平台营销购时锁 OP 等。
