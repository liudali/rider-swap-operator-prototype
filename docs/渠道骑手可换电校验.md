# 渠道骑手可换电校验

> **这是什么**：扫码换电前，系统判断渠道骑手当天能不能取电——看个人剩余人天，还是只能还电。  
> **依据**：[天数池.md](./天数池.md) · [渠道结算模式规则.md](./渠道结算模式规则.md) · decision-126 · decision-151（按电池型号）  
> **写法**：[业务文档写作规范](./业务文档写作规范.md)

---

## 业务设定

### 一句话

渠道人天骑手换电前先过权益门：**当前可领电型号的个人剩余 ≥ 1**，且柜机取出电池**型号匹配**，才能取电；剩余为 0 或型号不匹配时**禁止换电**；若手里还拿着电池，只允许还电入柜。换型号须走收回→还电→再分配→再领电（decision-151）。**不再**推荐自费应急套餐。已取消整批预占闸门（decision-126）。

### 谁在什么时候触发

骑手 App / 小程序在**扫码换电前**调用权益校验；真正发起换电时还应再验一次。跨网/跨站是否允许，另走运营商换电范围策略，与本文独立。

### 结果怎么理解

| 情况 | 能否换电 | 能否还电 | 用户侧 |
|------|----------|----------|--------|
| 该型号个人剩余 ≥ 1 且电池型号匹配 | 能 | 能 | 正常换电 / 领电 |
| 型号不匹配（额度型号 ≠ 可取电池） | 不能 | 持电则可还 | 拦截；联系渠道按迁移流程换型号 |
| 个人无额度且持电池 | 不能 | 能 | 待还电；联系渠道再分配。占用从**对应型号**渠道池扣人天，不向骑手收现金（decision-136 / 142 / 151） |
| 无权益且未持电池 | 不能 | — | 拦截；渠道路径提示续配同型号 |
| 换型号迁移未完成 | 不能领新型号 | 持旧电可还 | 提示先还电并由渠道收回旧额度 |
| 个人套餐与渠道身份冲突 | 不能 | 视业务 | 提示先处理个人套餐 |

### 已取消

- 自费应急 SKU / 兜底对象：响应不再返回，界面不引导渠道骑手现场购短周期套餐。  
- 「团队额度使用规则」校验：已废止，不再因团队规则拒换。  
- **整批预占失败**作为换电闸门（decision-126）。

### 和换电开始的关系

1. 先做权益校验。  
2. 允许换电 → 再调换电开始；成功换电后**确认消耗** 1 人天（当日尚未确认时）。  
3. 不允许换电但允许还电且持电池 → 仅还电路径。  
4. 不允许换电且未持电池 → 展示失败原因。

### 验收相关

原型演示：个人无额度·待还电等。见 [acceptance-criteria.md](./acceptance-criteria.md) 与天数池相关条目。

## 实现附录（开发用）

> 业务读者可跳过。

### A. 接口

`POST /api/v1/entitlement/check`  
请求：user_id、cabinet_sn、可选 site_id / request_time（以服务端时间为准）。  
幂等：同用户+自然日可缓存；swap/start 前须再校验。

### B. 响应字段

allowed_swap、allowed_return、entitlement_type（day_pool / personal_pkg / none）、pool_id、battery_model、seller_operator_id、today_status（available / confirmed / pending_return / not_allocated / model_mismatch）、remaining_days、gate_reason（个人无额度 / 型号不匹配 / null）。  
历史字段 `reserved` / `预占失败` 废弃，读兼容可映射到 available / 个人无额度。  
**废弃**：fallback 自费兜底对象。

### C. 错误码

| 码 | 含义 |
|----|------|
| E001 | 未登记渠道且无有效个人套餐 |
| E002 | ~~预占失败~~ → 映射为个人无额度 / 剩余不足 |
| E003 | 团队规则（已废止） |
| E004 | 个人与渠道身份冲突 |
| E006 | 个人无额度·待还电 |
| E007 | ~~预占失败·待还电~~ → 与 E006 合并 |
| E008 | 电池型号与人天额度不匹配 / 换型号迁移未完成 |

### D. 流程

```
扫码 → entitlement/check（该型号 remaining_days ≥ 1 且型号匹配）
  ├─ allowed_swap → swap/start → 确认消耗 1（记入对应型号池）
  ├─ 仅还电（持电池 / 迁移中）
  └─ 拦截 + gate_reason=个人无额度 | 型号不匹配
```
