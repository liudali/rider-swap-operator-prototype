# 站点实景照片

> **这是什么**：运营商在站点主档上传门头/柜机照片，骑手在站点详情看到同一组图；不传则用系统默认背景。  
> **依据**：[decision-144](../decisions/decision-144.md) · [PRD.md §5.15](./PRD.md) · [骑手端PRD.md](./骑手端PRD.md)  
> **原型**：运营商 `站点管理 → 站点信息 → 编辑`；骑手 `prototype/mobile/index.html` IA-01a / IA-01b

---

## 业务设定

骑手找站时要确认「这是不是眼前这家店」。照片降低走错门的成本；不传也不能让详情页像坏了，所以空图走默认背景。

## 规则

| 项 | 口径 |
|----|------|
| 必填 | 否 |
| 上限 | 9 张 |
| 格式 | jpg / png / webp |
| 单张大小 | ≤ 5MB `[假设]` |
| 顺序 | 上传顺序 = 轮播顺序；第一张 = 封面 |
| 空态 | 骑手端头图 = 系统默认背景（全网同一套） |
| 谁可改 | 运营商站点信息编辑权限；渠道专属站可改照片（与地址、坐标同级） |
| 谁可见 | 骑手：在营且对该用户可见的站点详情 |

## 页面规格

### 运营商 · 站点信息 · 新增/编辑

| 项 | 说明 |
|----|------|
| 字段 | 实景照片（多图）、封面标记、骑手端头图预览 |
| 枚举 | 无。格式限制见上表 |
| 空态 | 0 张；预览区直接显示默认背景；可点「填入示例实景（演示）」 |
| 错误态 | 超过 9 张拦截；非 jpg/png/webp 拦截；单张 > 5MB 拦截 |
| 权限差异 | 无 `sites.edit` 只读列表、不能打开编辑。渠道专属站名称/类型只读，照片可改 |

列表「实景」列：有图显示封面缩略图 + 张数；无图显示「默认 / 未上传」。保存后立即作用于骑手端（无审核队列）。

### 骑手端 · 站点详情

| 项 | 说明 |
|----|------|
| 入口 | 首页地图点 Marker |
| 字段 | 实景轮播（或默认背景）、站点名、地址、柜机摘要、电池型号、可用电池、充电中、开始导航 |
| 枚举 | 头图两种：有实景 / 默认背景 |
| 空态 | 无照片 → 默认背景，站点名与柜机信息仍展示 |
| 错误态 | 无经纬度 → 开始导航不可用并提示「该站点暂无坐标，无法导航」 |
| 权限差异 | 个人与人天同一页；专属站仅白名单（二期） |

轮播：多于 1 张显示圆点；点击头图切换下一张。默认背景不显示圆点、不出现「暂无图片」空空如也的破图。

## 异常与边界

- 删光照片后，骑手端立刻回默认背景。  
- 建设中 / 已停用站不出现在骑手地图，即使有照片。  
- 地图 Marker 本身不加缩略图。  
- 不向骑手征集照片、不做人工审图。
