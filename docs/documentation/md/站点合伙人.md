# 站点合伙人

> **这是什么**：运营商按**站点**给场地方/物业（个人或公司）设分润比例；合伙人可独立登录看明细、向运营商申请提现。  
> **依据/关联**：[合伙人站点分佣.md](./合伙人站点分佣.md) · [PRD.md](./PRD.md) §5.13 · [合作模式与分账.md](./合作模式与分账.md) §9 · [站点合伙人-Mock字段清单.md](./站点合伙人-Mock字段清单.md)  
> **写法**：[业务文档写作规范](./业务文档写作规范.md)

## 业务设定

### 一句话

一站可绑多位合伙人；同一人可绑多站、各站比例不同。平台仍先拿 1%，合伙人份额从运营商那 99% 里切出。渠道人天、跨网费不算分润。

### 谁干什么

| 角色 | 职责 |
|------|------|
| 运营商 | 建档案（个人/公司）；在站点上添加合伙人并设比例；看分润明细；审提现 |
| 站点合伙人 | 只读看绑定站与分润；向运营商申请提现（独立登录） |
| 平台 | 不参与合伙人谈判；C 端仍是「平台 1% + 运营商净额」，合伙人从运营商份额切 |

### 和渠道商、站点支出的区别

- **渠道商**：B 端采购人天的买方。  
- **站点合伙人**：场地分润方。  
- **站点支出**：运营商付给场地方的场费/电费；合伙人分润是从经营收入切。可同人不同账。

### 个人还是公司（建档锁定）

建档时选类型后锁定；按类型补齐开户资料后，才能绑站与提现。

| 类型 | 开户要填什么 |
|------|----------------|
| 个人 | 真实姓名、身份证、手机、个人银行卡（户名/开户行/账号） |
| 公司 | 公司全称、统一社会信用代码、法定代表人、联系人、电话、对公账户 |

开户状态：待开户 → 已开户。未开户不可绑站、不可提现。演示里「浦东场地运营公司」仍为待开户。

### 绑定与比例

1. **粒度**：按「站点 × 合伙人」绑定；一站可多位。  
2. **同人多站**：各站比例可不同。  
3. **上限**：同一站点所有合伙人比例合计不超过 99%（与平台 1% 凑满 100%）。  
4. **主入口**：站点管理 → 合伙人；档案与明细在「站点合伙人」菜单。

示例：浦东站 — 王场地方 25% + 李物业 5%；世博站 — 王场地方 25%。

### 钱怎么切（白话）

以该站**个人用户已确认可分配收入**为基数：

1. 先切平台 1%；  
2. 再按本站各合伙人比例切；  
3. 剩下归运营商（尾差也归运营商）。

**不算进分润**：渠道人天、设备租赁白名单、跨网设备费。

### 何时生效

添加、调比例、解绑 → **立即生效**，并留下变更记录；已经切过的历史分润不回溯。

### 渠道专属站

默认不参与分润；若要绑，须运营商显式配置。

### 后台落在哪

**运营商**

| 位置 | 做什么 |
|------|--------|
| 站点 → 合伙人 | 添加/解绑、设本站比例（主配置） |
| 站点合伙人 → 档案 | 个人/公司档案 |
| 站点合伙人 → 分润绑定一览 | 只读汇总，可跳转站点配置 |
| 站点合伙人 → 分润明细 | 按站/人/日期查切分 |

**站点合伙人（独立登录）**

| 位置 | 做什么 |
|------|--------|
| 总览 | 累计/本月分润、绑定摘要、最近分润 |
| 我的站点 | 各站当前比例（自己改不了） |
| 分润明细 | 本人切分行，可按站/日期筛 |
| 提现结算 | 向运营商申请代付 |
| 收款账户 | 按类型看/补开户资料 |

提现由**运营商审核**打款，不是平台审。演示登录：「站点合伙人 · 王场地方」。

### 验收（白话）

| # | 场景 | 预期 |
|---|------|------|
| 1 | 一站多合伙人 | 浦东：王 25% + 李 5%，合计 30% |
| 2 | 同人多站 | 王：浦东 25%、世博 20%，各站独立 |
| 3 | 开户闸门 | 待开户不可绑站；个人/公司字段不同 |
| 4 | 站点配置 | 站点列表「合伙人」打开抽屉 |
| 5 | 改比例 | 立即生效并留痕 |
| 6 | 渠道人天 | 不分润 |
| 7 | 合伙人登录 | 可见自己绑定站与比例；可演示提现 |
| 8 | 提现 | 须已开户；向运营商申请 |

## 实现附录（开发用）

> 业务读者可跳过。字段名、实体、决策索引集中于此。

### A. 清分公式（多合伙人）

计提基数 `B` = 该站点个人用户已确认可分配收入。

```
platform_amount   = round(B × 1%, 3)
partner_i_amount  = round(B × R_i / 100, 3)
operator_amount   = B − platform_amount − Σ partner_i_amount
```

不计入：渠道人天、设备租赁白名单、跨网费。细则见 [合伙人站点分佣.md](./合伙人站点分佣.md)。

### B. 字段建议

| 实体 | 字段 |
|------|------|
| `SitePartner` | `id`, `operator_id`, `partner_type`（个人/公司，建档锁定）, `account_status`（待开户/已开户）, `name`, `id_no`/`license_no`/`legal_name`, `contact_name`, `phone`, `bank_*`, `status` |
| `SitePartnerBinding` | `id`, `site_id`, `partner_id`, `rate_pct`, `pending_rate_pct`, `effective_at`, `status` |
| `SplitLine` | `site_id`, `partner_id`, `partner_rate_pct`, `share_base`, `partner_amount`, … |

开户闸门：绑站 / 提现均要求 `accountStatus=已开户` 且启用。渠道专属站：`channel_dedicated=true` 默认不参与。
