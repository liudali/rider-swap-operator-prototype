## 4. 分模块

**平台设置**：套餐字段（城市×型号×SKU、生效方式、激活期限）合理。押金微信/芝麻只读阈值合理。跨网双开关文案正确。脏价格与分销校验见缺陷卡。

**渠道**：签约可新增；链接类佣金及时到付摘要在。渠道订单确认到账入口在（本轮未点超限单）。权益人天池可调额度。

**站点 / 设备**：新增站点过松。换电柜可编辑进详情，IoT 诚实标注。电池型号列错误。

**订单 / 流水**：换电订单真实、含归还/换出电池。资金实收支付+退款出款已接。清分有快照缺失行。

**平台服务**：保证金账户数字可读；与跨网页信用口径不一致。服务费页空态诚实。往来概况已接。

**用户 / 收款**：现金押金入口在。收款账户招商+商户号/门店号+变更对公。
