## 业务设定

### 一句话

一期只交清单里点名的菜单；没写的一律二期（原型可逛、侧栏标二期、一期验收不测）。骑手端整端属一期。

### 怎么读本清单

1. 先看「一期菜单边界」——这是唯一交付真源。  
2. 再按角色扫「已实现 / 部分实现 / 二期」——图例见下。  
3. 「不应具备」= 故意不做，避免越权。  
4. 商业关系与跨网、1% 用白话记住原则；字段级与演示账号在附录。

### 一期菜单边界（白话真源）

| 角色 | 一期交付什么 |
|------|----------------|
| 运营商 | 平台设置（个人套餐价·城市底价；开通方式+有效期；价格分区二期；SKU：包月30/7/1天/次卡10次/单次）；渠道管理（人天池、骑士卡）；站点管理（仅站点信息）；我的设备（换电柜、电池）；订单与服务（套餐单、换电单、用户押金、退款管理）；我的流水（资金实收、清分明细、提现申请）；平台服务（保证金、平台服务费、往来）；用户；收款账户 |
| 平台管理员 | 用户管理（用户信息，页内待审认证）；订单（套餐/换电/渠道商订单）；设备（电柜/电池/电池型号，含批量导入）；流水（用户支付/运营商之间/平台提成）；平台账户；运营商管理（列表、提现审核、平台服务费、渠道商管理）；保证金管理；平台统价（跨网服务费、人天标准日值） |
| 客户·人天池 | 额度池、骑手登记（含团队）、额度分配、消耗明细 |
| 分销商·链接类 | 套餐与链接、购卡记录、佣金对账、收款账户 |
| 骑手端 | 个人套餐 + 人天池双故事线（整端一期） |

二期举例（未穷尽）：总览、员工、变更记录、服务冻结、站点合伙人/场费电费、用户押金统计、人天零售价/异常、设备租赁、激活码、融资、平台营销、资金方角色等。

### 商业关系（白话）

- **渠道**向一家或多家签约运营商买人天（一运营商一池）；成员可跨网换电；用户归属=卖额度的运营商。渠道主体由运营商在「渠道销售」新增维护；平台只读监管。  
- **运营商**向资金方融资设备；服务个人用户 + 承接渠道成员；跨网设备费经平台清分，平时扣保证金，保证金为 0 才动信用额度。  
- **智格平台**：物联网、用户端、规则、对账；收约 1%（个人支付清分 + 渠道人天确认消耗计提）。

### 各角色能力摘要（白话）

**平台管理员**：管全网用户/订单/设备绑定与型号、流水、统价、保证金充值确认、运营商提现审核与服务费比例；不做渠道主体新增、不做运营商定价编辑、不操作渠道额度分配。

**运营商**：定价与渠道四模式签约、站点与设备、订单与押金退款、三台账与平台服务、用户与收款账户；一期不含总览繁忙度/合伙人/融资等（见边界）。不应具备渠道买方额度池与团队登记。

**渠道侧**：结算模式四选一，侧栏按模式变。角色类型为客户·人天池 / 分销商·链接类 / 客户·设备租赁 / 分销商·激活码；人天池管额度与骑手；链接类管推广与佣金；设备租赁/激活码属二期。

**资金方（二期）**：授信与放款申请确认；不做 C 端经营；直租租金轨道已移除。

**站点合伙人**：独立登录，只读绑定与分润，向运营商提现；不能改站、不能改比例、不能碰定价/设备/订单。

### 两类用户与跨网（白话）

| 用户类型 | 归属哪家运营商 |
|----------|----------------|
| 个人套餐 | 卖套餐的那家 |
| 渠道成员 | 卖人天额度的那家 |

换电时还会带上柜机归属、电池归属。三者不全是同一家时，产生跨网设备费（柜机/电池单价由平台统价），经平台日清；运营商只见平台代收/代付，不见对手方。保证金用光后才用信用；信用也用光 → 关闭该运营商用户跨网。

### 平台约 1%（白话）

| 场景 | 何时计 | 怎么收 |
|------|--------|--------|
| 个人支付 | 支付成功 | 支付通道分账到平台 |
| 渠道人天 | 确认消耗（换电或持电池） | 按平台标准人天价 × 1% 向额度售卖方计提 |

额度必须经平台池生效；消耗必计提，防线下绕过。

### 主要风险（白话）

| 风险 | 等级 | 怎么缓 |
|------|------|--------|
| 渠道线下绕过平台 | 高 | 收费锚点改为确认消耗；额度平台发放 |
| 换电三元组错 | 高 | 物联网强制上报，后台只读 |
| 私下结跨网费 | 高 | 强制平台代收代付 |
| 保证金+信用都用尽仍跨网 | 高 | 自动关该运营商用户跨网 |
| 批发价过低逃费 | 中 | B 端 1% 按平台标准人天价，不跟批发价绑死 |
| 未绑定设备被运营商接入 | 高 | 仅平台可绑设备 |
| 文档与原型过期 | 高 | 大改后同步本清单与验收 |

### D. 渠道侧角色（四模式）

**客户·人天池（CH-SF）**：一期 = 额度池、登记（含团队）、分配、消耗明细；批量导入含 xlsx；无团队周期上限（已取消）。**余额不足** = 可用 &lt; 在职×10（与顶栏/短信同一条，decision-113）。线下增购填流水号，附言=采购单号；不填转账日（decision-114/115）。默认团队只读；其它团队名称唯一，无在职成员可停用/删除（decision-116）。B2B 不支持在线退池。零售价/异常/信用/变更记录/员工多为二期。

**分销商·链接类（CH-CARD）**：一期 = 套餐与链接、购卡记录、佣金对账、收款账户。不含渠道信用额度、不含员工。

**客户·设备租赁（CH-RENT）·二期**：白名单套餐/订单（SKU 对齐个人套餐：包月30天/7天/1天/次卡10次/单次换电 × 型号，含开通方式与有效期）、收款账户、月租、租赁设备、电池持有、跨网往来、信用等。

**分销商·激活码（CH-ACT）·二期**：AC 批发铸码、库存、作废审批、核销记录、信用等。

### E. 资金方 · 站点合伙人

资金方（二期）：总览、放款申请、收款账户、员工（可配 `finance.drawdown`）。不应具备 C 端/渠道经营；直租已移除。

站点合伙人：总览 KPI、我的站点（比例只读）、分润明细、提现结算、收款账户（分型开户）。不应具备站点 CRUD、档案维护、定价/渠道/设备/订单、全局流水。
