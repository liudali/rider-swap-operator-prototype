# 任务：美团类 SDK / 第三方渠道包对接 · 已取消

> **这是什么**：曾考虑的「美团 App 内购套餐，经 SDK 推单到换电平台」对接方案。  
> **状态**：**已取消**（2026-06-12 产品拍板）；不纳入一期及近期路线图。  
> **替代**：骑士卡差价模式（渠道批发购卡 → 持卡骑手 → 平台代收零售 + 对账单差价线下结）。  
> **关联**：[渠道结算模式规则.md](./渠道结算模式规则.md) · [竞品借鉴决策记录.md](./竞品借鉴决策记录.md) C-05  
> **写法**：[业务文档写作规范](./业务文档写作规范.md)

## 业务设定

### 一句话

不做美团 / 第三方 App 的 SDK 推单；渠道走骑士卡差价，不靠外部 App 推订单。

### 为什么取消

- 与当前 B 端渠道三种（后扩展为四）结算模式架构不一致。  
- 一期聚焦：渠道购卡 + 持卡分配 / 链接分销，不引入第三方 App 订单通道。

### 替代怎么做

骑士卡渠道：批发购卡 → 维护卡库存 → 分配给持卡骑手 → 用户按零售价支付（平台代收）→ 与渠道按差价线下对账结算。演示账号为「骑士卡渠道」，不是 SDK 推单渠道。

### 原型与菜单

后台**没有**「渠道销售 → SDK 对接」一类 Tab；勿按原 SDK 方案验收。
