# 渠道结算模式规则

> **这是什么**：渠道商与运营商怎么签约、用户怎么拿到换电权益、平台 1% 何时计提、钱怎么走。

## 业务设定

### 一句话

一期渠道主要两种活法：**人天池**（先批发额度再分给骑手）和**链接类分销**（推广链接让用户直购套餐拿佣金）。设备租赁、激活码、平台营销整块标**二期**。一期每渠道先只签一家运营商；用户跨网换电继承该运营商的换电范围策略。

### 共性规则

| 规则 | 说明 |
|------|------|
| 签约 | 一期每渠道仅签一家运营商 |
| 用户归属 | 经渠道拿权益的用户，归属一般为签约运营商（设备租赁白名单套餐收款另有约定） |
| 跨网 | 继承运营商换电范围（见 [换电范围策略.md](./换电范围策略.md)） |
| 渠道免押 | **人天池 / 设备租赁 / 激活码**：押金责任算渠道（见渠道信用）。**链接分销**：用户直购，走个人押金/免押，**不适用**渠道信用 |
| C 端收款清分 | 有在线支付的：支付成功实时清分平台 1% |
| 人天不足 | **不**再引导骑手自费买应急套餐；仅可还电，渠道续配 |

### 模式一：人天额度池（一期）

渠道向运营商批量买人天 → 分给骑手 → 按日预占确认扣天。采购时款已结清；确认消耗时平台按标准人天价 × 1% 向运营商计提。详规见 [天数池.md](./天数池.md)。

### 模式二：链接类分销（骑士卡等 · 一期）

渠道是**推广销售渠道**，不是批发入库再发卡：

1. 运营商定正式零售价；与各渠道谈**渠道专享价**（须 ≤ 正式价）和佣金。  
2. 渠道在「套餐与链接」生成推广链接 / 二维码；**不可改价**。  
3. 用户点链接或扫码 → 直达运营商小程序 → 登录实名 → **首笔**购卡按专享价（见下「专享价适用范围」）→ 权益即时开通。  
4. 款进**运营商子商户**；支付成功：平台 1% + 运营商净额；可选「佣金及时到付」再分一截给渠道子商户。  
5. **默认佣金**：线下结，平台出月度佣金对账。  
6. **不扣人天池**；押金按个人用户规则。

**24 小时归因窗口**

- 首次点击/扫码有效链接起 24 小时内，用户**首笔**购买该渠道授权 SKU（且**当前无生效个人套餐**、**此前无个人购卡成交**）可享**渠道专享价**。  
- **续费**（已有生效个人套餐）或**再次购卡**（曾成交过个人购卡，含套餐到期/退款后再买）：一律按运营商**正式零售价**，不再享渠道专享价；订单**不写**新的渠道佣金归因。  
- 窗口内再点**同渠道**其他链接：**不**重置 24h；点**其他渠道**链接：按最后触达**重置** 24h（仍仅首笔未购用户可享专享价）。  
- 过期未付：恢复正式零售价。从未点渠道链接的用户：正式价、无渠道标记、无佣金。

**多渠道**：同一运营商可签多家链接类渠道；在「平台设置 → 渠道分销价」按渠道 × 套餐分别配专享价与佣金，并可横向对比。

**后台（渠道）**：总览、结算说明、套餐与链接、购卡记录、佣金对账、变更记录。不含渠道信用额度、不含员工分工（主体账号即可）。

**已废弃**：渠道批发购卡 → 库存 → 持卡分配；第三方 App SDK 对接。

### 模式三：设备租赁（二期）

渠道租运营商的柜/电，付**统一月租**（增删设备不改月租，除非重签）。运营商建**专属站点**（不对公众开放，仅白名单地图可见）。渠道自己维护白名单：

| 类型 | 换电条件 |
|------|----------|
| 白名单免费 | 月租已覆盖，免购套餐即可换电 |
| 白名单付费 | 须买渠道自定的「白名单套餐」；款进**渠道子商户**，平台支付成功抽 1% |

- 不扣人天池；欠月租 → 停服（不可换电），**不**走 C 端应急套餐。  
- 运营商停用渠道主体 → 名单内**不可取电**，**仍可还电**；提示联系管理员续费。  
- 可选开通跨网：渠道缴跨网保证金，跨网费由渠道承担（小型运营商视角）。  
- 渠道侧另有：白名单套餐/订单、收款账户、月租账单、租赁设备、电池持有（只读）、跨网往来账、渠道信用、员工。

### 模式四：激活码（二期）

渠道批发激活码（运营商确认到账入库）→ 发给骑手 → 小程序输码开通套餐。**用户不经平台付款**。平台 1% 在**码核销成功**时，按「标准人天价 × 码服务人天 × B 端费率」向签约运营商计提（与批发单价无关）。一码一用。

### 四模式对照（白话）

| | 人天池 | 链接分销 | 设备租赁 | 激活码 |
|--|--------|----------|----------|--------|
| 渠道角色 | 买额度 | 推广卖货 | 租设备 | 批发码 |
| 用户怎么拿到权益 | 分配人天 | 链接购套餐 | 白名单 ± 渠道套餐 | 输激活码 |
| 平台 1% 何时 | 确认消耗 | 购卡支付成功 | 月租支付 + 白名单购套餐 | 码核销 |
| 骑手是否向平台付款 | 否（不足仅还电） | 是（专享价） | 付费白名单才付 | 否 |

### 平台营销（二期 · 非第五种渠道模式）

平台 opt-in 运营商发**立减券**推广链接（必须锁定运营商）；与链接分销并行。实付进锁定运营商子商户；支付成功抽 1%；营销服务费协议月结；券成本默认运营商让利。详规见 [平台营销-PRD.md](./平台营销-PRD.md)。

### 验收相关

链接归因、佣金对账、人天池见各专文与 [acceptance-criteria.md](./acceptance-criteria.md)。

## 实现附录（开发用）

> 业务读者可跳过。

### A. 交付边界

| 模式 | 代号/角色 | 一期 |
|------|-----------|------|
| 人天池 | 客户·人天池 · CH-SF | ✅ |
| 链接类 | 分销商·链接类（原卡差价/渠道分销；演示主体可称骑士卡） | ✅ |
| 设备租赁 | 客户·设备租赁 · CH-RENT | 二期 |
| 激活码 | 分销商·激活码 · CH-ACT | 二期 |
| 平台营销 | channel_id=PLATFORM | 二期 |

### B. 链接分销 · 佣金及时到付

- 开关：渠道管理 → 签约渠道 → 编辑（仅链接类）。  
- 前置：渠道收款账户子商户已开通。  
- 支付成功同步：平台 1% + 渠道佣金比例 + 运营商净额。  
- 演示：CH-CARD 开 9%；CH-DELIV 未开（线下结）。

### C. 链接字段与 URL

`package_id` / `sku_id`、`link_code`、`purpose`、`link_url`（小程序路径含 op/ch/lnk/可选 sku）、`qr_code`；每条链接独立点击/成交统计。  
**专享价适用范围**

| 场景 | 价格 | 渠道标记/佣金 |
|------|------|---------------|
| 归因窗口内 · 首笔购卡（无在服个人套餐、无历史个人购卡成交） | 渠道专享价 | 写 `channel_id`、首触 `link_code` |
| **续费**（在服个人套餐再买） | 运营商正式零售价 | 否 |
| **再次购卡**（曾购过个人套餐，含到期/退款后再买） | 运营商正式零售价 | 否 |
| 窗口内购非授权 SKU | 正式零售价 | 否 |

归因：`attribution_start` + 24h；仅**首笔专享价成交**订单写 `channel_id` + 首触 `link_code`。

### D. 设备租赁要点

- 专属站：`channel_dedicated`、`public_open=false`；非白名单扫码 `E_WHITELIST`。  
- 停服：`E_LEASE_CHANNEL_SUSPENDED`；可还电。  
- 白名单套餐：与个人套餐同 SKU 预设（包月30天/7天/1天/单次换电）× 电池型号 × 渠道零售价；`seller_channel_id`；运营商退款管理不处理该笔。  
- `userOwner` 可为渠道（小型运营商）；`device_owner_id` 仍为签约运营商 U。

### E. 激活码计提

`标准人天价 × 服务人天 × B 端费率`；代扣优先保证金，为 0 再占信用额度。
