# 运营商提现规则

> **这是什么**：运营商子商户里已清分的钱，如何申请提到银行卡；与「支付成功即时清分」分开。  
> **依据**：[合作模式与分账.md](./合作模式与分账.md) · [融资管理-PRD.md](./融资管理-PRD.md) · [PRD.md](./PRD.md) · 文末决策索引  
> **写法**：[业务文档写作规范](./业务文档写作规范.md)

## 业务设定

### 一句话

骑手付款成功后份额已清分；**要提到银行卡，必须走平台内部提现工单**。审核通过后，平台向支付渠道发起转账指令：从运营商**收款账户**（演示为招商银行对公户）转到工单上填写的**转账银行卡**。本规则只约束**运营商**；设备租赁渠道白名单套餐款不走这套审核。

### 清分 ≠ 提现

| 环节 | 何时 | 结果 |
|------|------|------|
| 清分 | 支付成功即时 | 子商户入账，状态「已清分」 |
| 提现 | 工单 + 平台审核 + 转账指令 | 从收款账户转到本笔转入卡 |

### 可提现余额（一期）

可提现 = 已清分累计 − 已提现 − 待审/处理中申请金额（不为负则取 0）。

| 项 | 含义 |
|----|------|
| 已清分 | 实时清分进子商户、尚未提走的运营商净额 |
| 已提现 | 状态为「已提现」的金额合计 |
| 待审/处理中 | 「待审核」「审核通过」「处理中」占用额度 |

**二期**（与融资管理同期）：再减去「本月融资待还」预留，避免待还到期前过度提现；还款确认后释放。一期原型可展示该 KPI（标二期），**不扣减**、申请单不写待还预留。

### 提现怎么走

1. 运营商在「我的流水 → 提现申请」填金额（不得超过可提现）。  
2. **转出账户** = 「收款账户」绑定的对公卡（未绑定不可申请）。演示绿色出行为招商银行。  
3. **转入**须填转账信息：开户名称、**银行卡号**、开户银行、开户支行；联行号选填。默认同收款账户，可改为其他对公卡。提交后快照到工单。  
4. 平台在「运营商管理 → 运营商提现审核」审工单。  
5. **通过**：确认转出/转入/金额后，向支付渠道发起转账指令 → 状态「已提现」，记到账时间。  
6. **驳回**须填原因；运营商可改后重提。

### 谁适用

| 主体 | 是否走本流程 |
|------|----------------|
| 运营商（C 端套餐收款） | 是 |
| 客户·人天池 | 否（B2B 采购时已结清） |
| 渠道 · 设备租赁 | 否（白名单款进渠道子商户） |
| 渠道 · 链接分销佣金及时到付 | 否（进渠道对公卡，若开启） |
| 平台自有 1% 收入 | 否（平台自结） |

### 申请单字段（运营商 · 提现申请）

| 字段 | 必填 | 说明 |
|------|------|------|
| 提现金额 | 是 | ≤ 可提现；>0 |
| 转出账户 | 只读 | 收款账户脱敏展示；未绑定不可打开表单 |
| 转账开户名称 | 是 | 2～64 字 |
| **转账银行卡号** | 是 | 8～32 位数字；默认同收款账户，可改 |
| 转账开户银行 | 是 | 如招商银行 / 宁波银行 |
| 转账开户支行 | 是 | |
| 联行号 | 否 | 填则须 12 位数字 |

空态：可提现=0、已有待审、未绑定收款账户 → toast 拦截，不打开表单。  
错误态：上表校验失败 → 表单内提示，不提交。  
权限：仅运营商申请；仅平台在「运营商提现审核」通过/驳回。驳回须填原因。

### 验收要点

- 支付成功 → 清分明细「已清分」。  
- 一期可提现不含融资待还扣减。  
- 申请占用待审额度；驳回释放；通过记已提现。  
- **未绑定收款账户不可提现**。工单必须有转账银行卡号。  
- 默认同收款账户；可改转入卡；历史工单不受事后改收款账户影响。  
- 设备租赁收款页注明不适用本审核。

## 实现附录（开发用）

> 业务读者可跳过。

### A. 公式

```
一期：max(0, 已清分 − 已提现 − 待审处理中)
二期：max(0, 一期可提现 − 本月融资待还)
本月融资待还 = 还款日历当月非已还清的 (dueAmount − paidAmount) 合计
```

### B. 状态与实体

`WithdrawalRequest`：金额、转出账户快照、转入卡（开户名称/银行卡号/开户银行/开户支行/联行号）、状态（待审核 / 审核通过 / 处理中 / 已提现 / 已驳回）、申请/审核/指令/到账时间、驳回原因。  
`month_due_reserved`：二期字段；一期恒 0 / 不展示。

### C. 流程示意

```mermaid

  B -->|通过| C[向支付渠道发转账指令]
  B -->|驳回| D[结束可重提]
  C --> E[招商银行户转到转入卡]
```
