# 运营商 · 逾期管理 验收标准

角色：运营商。入口：订单与服务 → 逾期管理。  
独立演示：`prototype/index.html`。

## 菜单与权限

| # | 项 | 预期 |
|---|----|------|
| AC-01 | 菜单位置 | 运营商「订单与服务」下有一期菜单「逾期管理」，不标二期 |
| AC-02 | 角色裁剪 | 平台、人天池、链接类侧栏无此菜单 |
| AC-03 | Tab | 个人套餐逾期 / 人天池占用 / 已完结 / 逾期设置 |

## 名单与区分

| # | 项 | 预期 |
|---|----|------|
| AC-04 | 收录条件 | 仅「当前持电」且（个人套餐已结束 **或** 人天剩余 = 0） |
| AC-05 | 类型互斥 | 同一用户同一时刻只出现在一个进行中 Tab；类型文案为「个人套餐逾期」或「人天池占用」 |
| AC-06 | 用户信息 | 详情含 ID、姓名、脱敏手机、权益来源、套餐或渠道/团队 |
| AC-07 | 电池信息 | 详情含 SN、型号、进入逾期/占用时刻；无 IoT 时 SOC 为 — |
| AC-07b | 详情可见 | 点「详情」打开右侧抽屉（非仅遮罩）；含用户信息、电池信息、逾期时间、逾期费用（人天为占用时间/已扣人天） |
| AC-08 | 结束原因 | 个人列表能区分「到期」与「次数耗尽」 |
| AC-09 | 空态 | 筛选无数据时表格「暂无逾期持电用户」，KPI 为 0，不是报错 |
| AC-10 | 不收录 | 未持电、服务中持电、人天剩余 ≥ 1 持电，均不进进行中名单 |

## 个人套餐计费

| # | 项 | 预期 |
|---|----|------|
| AC-11 | 公式 | 应付 = 逾期天数 × 日费；逾期天数 = max(1, ceil(小时/24)) |
| AC-12 | 不足一天 | 进入逾期后 10 分钟还电，天数 = 1，应付 = 1 × 日费 |
| AC-13 | 只收个人 | 人天池占用 Tab 无「逾期费用」现金列 |
| AC-14 | 列表字段 | 个人列表展示 **逾期时间、逾期费用**；**不**展示「扣款 / 在押已抵 / 待补缴」 |
| AC-15 | 日费设置 | 逾期设置可改 x；空或 ≤ 0 保存失败，提示「日费须大于 0」 |
| AC-16 | 已扣不退 | 付清或还电进入已完结后，占用费不冲回 |
| AC-27 | 先付后还 | 个人占用费未结清时不可进入还电（扫码/模拟还电拦截） |
| AC-28 | 不封顶 | 系统计费 = 天数 × 日费，不以押金或天数截断 |
| AC-29 | 押金不抵 | 占用费不从在押押金划扣；押金还电后按原规则退 |
| AC-30 | 应付=0 放行 | 运营商将应付改为 0 后，无需支付即可还电 |
| AC-36 | 修改费用 | 详情可改应付；0 ≤ 新应付 ≤ 系统计费；原因为空则失败 |
| AC-37 | 减免日志 | 每次改价产生一条日志：时间、操作人、原应付、新应付、原因 |
| AC-38 | 模拟支付 | 演示「模拟支付」后状态=已付清，可还电；资金实收出现电池占用费 |
| AC-39 | 不分润 | 占用费不进清分明细、不抽平台 1%、不切合伙人 |
| AC-40 | 收入模块 | 资金实收可筛/切到「逾期占用费」；KPI 展示占用费实收 |

## 人天池扣减

| # | 项 | 预期 |
|---|----|------|
| AC-17 | 扣池不扣骑手现金 | 人天池占用只扣渠道额度池可用，列表无应付 ¥ |
| AC-18 | 不足一天 | 剩余 0 且持电未满 24h，占用人天 = 1 |
| AC-19 | 不重复 | 当日已按日终持电扣过 1 人天的，当天不再记逾期占用 |
| AC-20 | 欠人天 | 池可用扣成负数，展示负值和「欠人天」 |
| AC-21 | 消耗明细 | 渠道消耗明细可看到触发动作「逾期占用」（演示在详情流水） |
| AC-22 | 恢复额度 | 渠道再分配使剩余 ≥ 1 后，该骑手离开进行中（演示「模拟续配」） |

## 操作与异常

| # | 项 | 预期 |
|---|----|------|
| AC-23 | 催还 | 进行中行可催还，toast 成功；不改变计费 |
| AC-24 | 还电 | 模拟还电后行进入已完结；电池不再持有 |
| AC-25 | 退押拦截 | 进行中个人逾期未还电，不得走押金退还（文案：请先还电） |
| AC-26 | 新购拦截 | 个人逾期未结清占用费，不可开通新套餐继续持电 |

## 骑手端展示

| # | 项 | 预期 |
|---|----|------|
| AC-31 | 个人服务卡 | 「套餐已结束·待还电」展示逾期天数与 **逾期费用 ¥**；未结清主按钮「支付占用费」 |
| AC-32 | 个人支付 | 支付占用费页展示应付；支付成功后才可扫码还电 |
| AC-33 | 未付拦截 | 未付清时扫码还电提示「请先支付电池占用费」 |
| AC-34 | 人天服务卡 | 展示已从渠道额度扣除 N 人天、**你无需支付占用费**；无现金应付；可直接还电 |
| AC-35 | 文案 | 使用「电池占用费」，不出现「罚款」 |
