# 合伙人站点分佣规则

> **这是什么**：个人用户在某站产生确认收入后，如何按「平台 1% + 本站各合伙人比例 + 运营商余量」切分。  
> **依据/关联**：[站点合伙人.md](./站点合伙人.md) · [合作模式与分账.md](./合作模式与分账.md) §9 · [功能结构与业务流程.md](./功能结构与业务流程.md)  
> **写法**：[业务文档写作规范](./业务文档写作规范.md)

---

## 业务设定

### 一句话

只切**个人用户**已确认可分配收入；渠道人天、跨网费不算。比例按站设、立即生效，历史不回溯；尾差归运营商。

### 先满足什么

| 步骤 | 谁做 | 说明 |
|------|------|------|
| 建站 | 运营商 | 维护站点 |
| 绑设备 | 运营商 | 柜机、电池（自有或租赁） |
| 加合伙人 | 运营商 | 档案：类型、名称、联系人、收款账户 |
| 站点绑定 | 运营商 | 站点管理 → 合伙人：一站可多位，各设本站比例 |

### 什么收入算、什么不算

- **算**：个人用户自购套餐的确认收入、关联换电确认收入。  
- **不算**：渠道人天用户、跨网设备服务费、平台 B 端 1% 台账。

### 比例怎么定

**没有合伙人时**

| 方 | 比例 |
|----|------|
| 平台 | 1% |
| 运营商 | 99% |

**有合伙人时（按站点）**

运营商为该站配置 1～N 位合伙人，各设本站比例（每位大于 0、不超过 99；全站合计不超过 99）。同一人绑多站时，各站比例独立。

| 方 | 比例 |
|----|------|
| 平台 | 1%（固定） |
| 合伙人各自 | 该站当日生效比例 |
| 运营商 | 99% 减去全部合伙人比例之和 |

合伙人从运营商原 99% 里切出，**不改**平台 1%。

示例：浦东站王 25% + 李 5% → 平台 1% + 合伙人合计 30% + 运营商 69%；世博站仅王 20% → 1% + 20% + 79%。

### 计提基数（白话）

该站、该运营商设备上，个人用户订单**已经确认**的可分配收入。包月按日（或按次）摊销后的当日/当笔确认额；换电关联个人套餐的确认片段。退款按原切分行冲正。

### 怎么算金额（白话）

1. **先算平台**：基数 × 1%，四舍五入到分后三位。  
2. **再逐个算合伙人**：基数 × 各自比例，各四舍五入到三位。  
3. **运营商** = 基数 − 平台 − 全部合伙人；**不再四舍五入**，吃掉全部尾差。

### 何时生效

| 项 | 说明 |
|----|------|
| 时点 | 运营商提交添加 / 调比例 / 解绑后**立即生效** |
| 口径 | 提交后的新确认收入按新规则；提交前已确认的不追溯 |
| 留痕 | 记操作时间、操作人、动作、前后比例、备注 |

示例：6 月 10 日 16:00 把某站比例从 30% 改为 25% → 16:00 前已确认不变；之后新确认按 25%。

### 验收（白话）

| # | 场景 | 基数 | 合伙人比例 | 平台 | 合伙人 | 运营商 |
|---|------|------|------------|------|--------|--------|
| 1 | 无合伙人 | 100 | 0 | 1 | 0 | 99 |
| 2 | 浦东 30% | 245 | 30% | 2.45 | 73.5 | 169.05 |
| 2b | 同人·世博 20% | 245 | 20% | 2.45 | 49 | 193.55 |
| 3 | 尾差示例 | 9.96 | 30% | 0.1 | 2.988 | 6.872 |
| 4 | 合伙人 12% | 245 | 12% | 2.45 | 29.4 | 213.15 |

| # | 场景 | 预期 |
|---|------|------|
| 5 | 16:00 改比例 | 立即生效并写变更记录；历史不回溯 |

## 实现附录（开发用）

> 业务读者可跳过。

### A. 金额公式（单笔 · 多合伙人）

```
platform_amount     = round(B × 0.01, 3)
partner_i_amount    = round(B × R_i / 100, 3)
operator_amount     = B − platform_amount − Σ partner_i_amount
```

尾差：先平台、再合伙人逐位、运营商吸收。

### B. 字段建议

| 字段 | 说明 |
|------|------|
| `site_id` | 站点 |
| `partner_id` | 合伙人（可空） |
| `partner_rate_pct` | 该站点收入确认日已生效的合伙人比例 |
| `effective_at` | 规则实际生效时间（提交时间） |
| `binding_log_id` | 本次添加/调比例/解绑对应的变更记录 |
| `share_base` / `allocatable` | 计提基数 B |
| `platform_amount` | 平台份额 |
| `partner_amount` | 合伙人份额 |
| `operator_amount` | 运营商份额 |
| `split_label` | 展示用，如「平台1%+合伙人30%+运营商69%」 |
| `user_type` | `personal` / `channel_day`；仅 `personal` 走本规则 |
| `device_owner_id` | 设备归属运营商 |
