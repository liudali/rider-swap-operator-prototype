# 低电外呼提醒方案 · 用户端验收标准

> 对应 PRD：`docs/PRD.md`  
> 对应原型：`prototype/index.html`  
> 验收范围：方案一——微信小程序引导用户把固定低电外呼号码添加到系统通讯录

## 1. 验收前提

- 外呼服务商已确认全平台使用唯一、固定的主叫外显号码；
- 正式号码仅用于低电提醒，不与营销、催缴等业务共用；
- 服务端返回联系人名称、号码、号码版本和配置状态；
- 小程序隐私保护指引已声明“使用你的通讯录（仅写入）”；
- 真机测试至少覆盖 iOS、鸿蒙及一个主流 Android 系统。

## 2. 主流程验收

### AC-01 换电成功后主动引导一次

**Given**

- 用户已登录；
- 本需求上线后该用户从未展示过换电添加弹窗（`swapPromptShown=false`）；
- 提醒号码配置有效，微信接口可用。

**When**

- 换电成功页展示完成。

**Then**

- 自动展示“别错过低电提醒电话”底部弹层；
- 展示联系人名称和完整提醒号码；
- 明确说明“仅写入，不读取”；
- 提供“添加到通讯录”和“暂不添加”；
- 记录 `low_battery_contact_prompt_view`，`entry=swap_success`，`user_once=1`；
- 曝光后写入 `swapPromptShown=true`（账号维度）；
- 页面不出现“未保存 / 已保存”状态。

### AC-01A 取电成功不弹窗

**Given**

- 用户已登录并首次成功领取电池；
- 提醒号码配置有效，微信接口可用。

**When**

- 领取成功页展示完成。

**Then**

- **不**自动弹出添加引导；
- 不写入 `swapPromptShown`；
- 开始「我的」7 天入口计时（`firstPowerEventAt`）；
- 结果页可保留手动「添加到通讯录」，`entry=first_pickup`。

**When**

- 用户只是打开首页或小程序，没有换电成功。

**Then**

- 不自动弹出添加引导。

### AC-01B 存量持电用户在下一次换电成功时补一次引导

**Given**

- 用户功能上线前已经持电，该用户从未展示过换电弹窗。

**When**

- 日常换电成功页展示完成。

**Then**

- 自动展示与 AC-01 相同的底部弹层；
- 记录 `entry=swap_success`、`user_once=1`。

### AC-02 每个用户换电弹窗只展示一次

**Given**

- 该用户已展示过换电添加弹窗；
- 用户曾选择暂不添加或关闭弹层。

**When**

- 用户再次领电成功、再次换电成功、号码版本变更，或重新进入首页。

**Then**

- 不再自动弹出添加引导；
- 不影响领取、换电和套餐服务。

### AC-02A 我的页 7 天内可直接添加

**Given**

- 用户已登录；
- 上线后已发生第一次取电或换电成功；
- 当前处于第 1–7 个自然日（含当天）。

**When**

- 用户打开“我的”页，点击「添加到通讯录」。

**Then**

- 不进入设置页即可发起添加；
- 调用链路与设置页相同（授权 → `wx.addPhoneContact` → 系统确认）；
- 记录 `low_battery_contact_save_click`，`entry=mine`；
- 不额外增加主动弹窗次数。

**And**

- 即使刚刚系统页返回成功，我的页仍展示「添加到通讯录」，不切换成“已保存”。

### AC-02B 第 8 天隐藏我的页入口，设置常驻

**Given**

- 用户首次取电/换电成功已满 7 个自然日（第 8 个日历日起）。

**When**

- 用户打开「我的」。

**Then**

- 不展示来电提醒卡片和「添加到通讯录」；
- 仍展示「设置」；
- 首页提醒保障卡同步隐藏。

**When**

- 用户进入「设置 → 来电提醒」。

**Then**

- 可再次添加，记录 `entry=settings`。

### AC-02C 上线后尚未取电/换电

**Given**

- 用户已登录，但本需求上线后从未取电成功或换电成功。

**Then**

- 「我的」不展示来电提醒卡片；
- 「设置 → 来电提醒」仍可进入。

### AC-03 用户允许通讯录仅写入权限

**Given**

- 用户从引导、我的页或设置页点击添加；
- 通讯录写入权限尚未决定。

**When**

- 用户在微信授权弹窗点击“允许”。

**Then**

- 记录 `low_battery_contact_permission_result=result:allowed`；
- 调用 `wx.addPhoneContact`；
- 用户可选择“新建联系人”或“添加到已有联系人”；
- 小程序不得读取已有联系人列表。

### AC-04 新建联系人并在系统页完成

**Given**

- 用户已允许权限并选择“新建联系人”。

**When**

- 系统联系人页打开，用户点击系统“完成”，API 成功回调。

**Then**

- 预填姓名“智格-电量过低提醒”、当前号码、公司、备注；
- 展示一次性完成反馈，文案说明小程序无法显示“已保存”；
- 关闭反馈后能力状态仍为可添加；
- 不写入 `savedNumberVersion` 或任何“已保存”产品状态；
- 记录 `low_battery_contact_system_result=result:api_success,system_mode:unknown` 及当前号码版本。

### AC-05 添加到已有联系人

**Given**

- 用户已允许权限并选择“添加到已有联系人”。

**When**

- 用户未选择已有联系人便点击完成。

**Then**

- 系统页阻止提交并提示“请选择要添加号码的已有联系人”。

**When**

- 用户选择已有联系人并确认完成。

**Then**

- `wx.addPhoneContact` 回调不提供最终的新建/合并结果，埋点统一记录 `system_mode=unknown`；
- 小程序不自行读取或展示真实联系人列表；
- 完成后不进入“已保存”状态。

### AC-06 添加入口始终可再次发起

**Given**

- 用户刚刚在系统页完成过一次添加。

**When**

- 用户进入“我的－来电提醒”或停留在我的页。

**Then**

- 仍显示「添加到通讯录」；
- 不显示“已保存”或“重新保存”；
- 辅助说明可随时再次添加；若联系人已存在，请在系统页选择“添加到已有联系人”；
- 不宣称系统正在校验联系人存在。

## 3. 异常与边界验收

### AC-07 用户拒绝权限

**When**

- 用户在微信授权弹窗点击“拒绝”。

**Then**

- 能力状态为 `permission_denied`；
- 展示微信小程序设置开启方法；
- 提供“稍后处理”；
- 不连续重新弹出权限申请；
- 不影响领取、换电、续费等核心服务；
- 埋点结果为 `denied`。

### AC-08 用户取消系统联系人页

**When**

- 用户已允许权限，但在系统联系人页点击“取消”。

**Then**

- 记录事件结果 `cancelled`；
- 不留下“未完成保存”页面状态；
- 返回来电提醒设置页，能力仍为可添加；
- 提示可稍后再次添加；
- 埋点结果为 `cancelled`。

### AC-08A 系统或 API 写入失败

**Given**

- 用户已进入系统联系人写入流程。

**When**

- `wx.addPhoneContact` 返回非拒绝、非取消的失败结果。

**Then**

- 展示一次性“系统未完成写入”错误；
- 提供重新添加入口；
- 关闭后不留下“保存失败”页面状态；
- 记录 `low_battery_contact_system_result=result:failed` 和错误码；
- 不影响领取、换电和套餐服务。

### AC-09 微信接口不支持

**Given**

- 当前微信基础库不支持 `wx.addPhoneContact`，或能力检查失败。

**Then**

- 状态为 `unsupported`；
- 展示“当前微信版本暂不支持”；
- 提供复制提醒号码的降级入口；
- 不展示虚假的系统保存成功结果。

### AC-10 提醒号码配置失败

**Given**

- 服务端未返回有效号码或号码版本。

**Then**

- 状态为 `config_error`；
- 不调用 `wx.addPhoneContact`；
- 不使用客户端历史硬编码号码兜底写入；
- 展示“重试加载”；
- 首页不展示可执行的错误添加按钮。

### AC-11 用户未持有电池

**Given**

- 用户当前未持有电池。

**Then**

- 首页展示“暂无在用电池”空态；
- 不展示 SOC 和低电告警；
- 若尚未首次取电/换电成功，不从「我的」展示来电提醒卡片，可从「设置」进入；
- 首次成功领电时开始 7 天窗口，但不主动弹窗。

### AC-12 号码版本变化

**Given**

- 本机曾引导过 v1；
- 服务端下发 v2 及新号码。

**Then**

- 展示新号码，不再把 v1 显示为当前有效号码；
- 可在设置/详情提示“号码已更换，建议重新添加”；
- 明确说明旧联系人需要用户在系统通讯录自行删除；
- 不为 v1 保留“已保存但过期”状态；
- **不**因号码变更再弹一次主动引导；
- 记录 `old_version=v1,new_version=v2`。

### AC-13 更换设备或清除缓存

**Given**

- 用户在新设备登录，或已清除小程序本地缓存。

**Then**

- 不使用账号服务端的旧设备“已保存”标记；
- **不**因换设备或清除缓存再次主动弹窗（以 `swapPromptShown` 账号记录为准）；
- 7 天窗口以服务端 `firstPowerEventAt` 为准；
- 服务端埋点不得包含设备通讯录内容。

### AC-14 重复联系人

**When**

- 用户再次点击“添加到通讯录”。

**Then**

- 允许再次进入系统添加流程；
- 文案优先提示可选择“添加到已有联系人”；
- 小程序不通过读取通讯录判断是否重复。

## 4. 来电效果验收

### AC-15 添加后的来电效果（真机，非产品状态）

**Given**

- 测试人员已在该手机通讯录中确认存在“智格-电量过低提醒”；
- 外呼实际主叫号码与添加号码完全一致。

**When**

- 低电专线呼入。

**Then**

- 系统来电页应优先显示“智格-电量过低提醒”；
- 仍需接受不同系统可能同时显示号码或拦截标签；
- 测试记录手机型号、系统版本、主被叫运营商和实际截图。
- 原型“添加后来电效果”仅为演示假设，不得写成小程序可判定已保存。

### AC-16 未添加时的来电效果（真机 / 原型演示假设）

**Then**

- 原型在“未添加时来电”场景仅显示号码，不虚构联系人名称；
- 产品不得保证未知号码不会被系统拦截；
- 不得按“已保存组 / 未保存组”统计接通率。

## 5. 页面完整性

| 页面/弹层 | 字段 | 枚举 | 空态 | 错误态 | 权限差异 |
|---|---|---|---|---|---|
| 登录页 | 产品名、登录按钮、协议 | 未登录/登录成功 | 无会话 | 微信授权失败 | 游客需登录后添加 |
| 首次领电成功页 | 电池 SN、领取电量、站点 | 成功/失败 | 无号码时隐藏添加卡 | 领电失败不触发引导、不开始窗口 | 仅已登录且领电成功 |
| 首页 | 电池 SN、SOC、预计可用 | 正常/偏低/过低 | 未持有电池；窗口外无提醒卡 | 电池数据加载失败 | 游客需登录 |
| 订单 | 订单号、结果、站点、时间、电池、权益 | 换电/购买/退租 | 当前分类无记录 | 加载失败可重试 | 仅本人订单 |
| 我的 | 用户、服务、7 天内提醒入口、设置 | 默认可添加/未授权；窗口内/外 | 未登录不展示添加；未发生取电换电无卡片 | 配置失败/不支持 | 登录后窗口内可直接添加 |
| 设置 | 来电提醒行 | 无 | 未登录先登录 | 不在列表层阻断 | 登录后常驻可进 |
| 来电提醒详情 | 名称、号码、来源、版本 | 能力状态见 PRD §9.1 | 未配置号码 | 配置失败/接口不支持 | 游客只看说明 |
| 微信授权弹窗 | 权限用途 | 允许/拒绝 | 不适用 | 授权组件异常 | 已授权可跳过 |
| 系统联系人页 | 姓名、手机、公司、备注 | 新建/合并 | 合并未选联系人 | 取消/写入失败 | 手机系统控制 |
| 来电效果页 | 联系人名、号码、呼叫状态 | 呼入/接通/拒绝/结束 | 无任务不展示 | 拦截/线路失败不在本期 | 终端系统控制 |

## 6. 埋点与数据验收

- [ ] 引导曝光、添加点击、授权结果、系统页结果、号码更换分别上报；
- [ ] 每个事件均携带 `number_version` 或可关联到对应版本；
- [ ] 主动引导与手动入口可通过 `entry` 区分（`swap_success` / `first_pickup` / `mine` / `settings`）；
- [ ] 换电弹窗曝光携带 `user_once=1`；
- [ ] 系统页结果可区分 `api_success/cancelled/failed`；
- [ ] 系统保存结果统一记录 `system_mode=unknown`，不虚构新建/合并结果；
- [ ] 不上传联系人列表、已有联系人名称、通讯录数量；
- [ ] 外呼平台回传可与用户及号码版本关联；
- [ ] 不得用“已保存组 / 未保存组”作为产品统计口径。

## 7. 体验与可访问性

- [ ] 主要按钮在 390px 宽移动视口内不截断；
- [ ] 页面支持鼠标和键盘操作，焦点状态可见；
- [ ] 弹窗提供明确主次操作，不依赖点击遮罩完成关键确认；
- [ ] 能力异常状态不只依赖颜色，同时展示文字；
- [ ] 用户拒绝、取消和错误后均有可恢复入口；
- [ ] 原型在桌面宽屏和 980px 以下布局均可阅读；
- [ ] 系统联系人模拟页明确标注“正式页面以手机系统为准”。

## 8. 发布判定

以下任一项不满足，判定为阻断上线：

- 外显号码并非固定号码；
- 正式号码承担非低电外呼；
- 用户拒绝权限后被阻断换电；
- 产品界面仍展示“已保存 / 未保存”；
- 系统取消仍被写成用户通讯录已保存；
- 隐私指引未声明通讯录仅写入；
- API 失败时仍写入硬编码历史号码；
- 缺少 iOS、鸿蒙或 Android 真机验证证据。
