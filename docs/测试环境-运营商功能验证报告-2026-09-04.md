## 3. 分模块要点

### 平台设置
- **个人套餐价**：城市 × 型号 × SKU、有效期、生效方式、激活期限、零售价 → 字段合理；演示价有 ¥0.00/¥0.02 测试脏数据。
- **押金设置**：应收、启用实缴、微信/芝麻门槛只读展示 → 合理。
- **人天批发价**：默认价 + 分渠道价、最低起购、对照平台标准价 → 合理。
- **渠道分销价**：正式价 / 专享价 / 佣金。  
  **严重问题**：`测试链接类渠道商` 行显示正式 ¥0.01、专享 ¥79.12 → **专享价高于正式价**，违反「专享 ≤ 正式」；保存校验或历史脏数据需修。
- **跨网换电**：平台∧运营商双开关、信用额度只读 → 与产品口径一致。

### 渠道
- **签约渠道**：结算模式、信用、调信用、编辑；链接类显示「佣金及时到付」摘要。
- **渠道订单**：人天批发确认到账/关闭 → 运营商职责正确。
- **渠道权益(待开发)**：已售池列表+额度调整仍可用，标签与能力略矛盾。

### 站点 / 设备
- 站点有经纬度缺失行（`-- , --`）；开放范围展示正常。
- 换电柜筛选项 placeholder「请输入站点/设备状态」→ 应枚举下拉。
- 电池型号 ID 显示为数字 `2`，可读性差（应用显示名称）。

### 订单 / 流水
- 套餐单：服务状态筛选未接入（同平台）。
- 换电单：真实接入，含跨网费、归还/换出电池。
- 退款：明确 Mock。
- 资金实收 / 清分：支付与冲正已接；渠道佣金列未接。
- **提现申请**：KPI（经营收入/可提现/处理中/已提现）+「发起提现申请」；表列为到账账户、审核/打款状态、银行流水号。  
  **无**转出账户、转账银行卡号、工单确认转账指令（与原型 decision-123 不一致）。

### 平台服务 / 用户 / 收款
- 保证金：余额、档位只读、充值申请 Tab。
- 平台服务费：仅 C 端事实，B 端诚实不造假。
- 运营商往来：明细/日清/周月汇总 Tab 较完整。
- 用户：有现金押金记录入口；换电次数/持有电池未接。
- 收款账户：招商银行 + 商户号/门店号 + 对公结算；可「变更对公」。

## 4. 优先缺陷

1. 渠道分销价允许或残留 **专享价 > 正式价**  
2. 提现模型未对齐新产品（转入卡号 / 通道指令）  
3. 设备筛选项文案像文本框、实为筛选枚举  
4. 电池「型号 ID」应对用户显示型号名  
5. 渠道权益/退款标「待开发」但页面可操作，需统一预期  
6. 测试脏价格（¥0 / ¥0.02）污染演示观感
