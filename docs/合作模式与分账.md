# 合作模式与分账

> **这是什么**：平台、运营商、渠道、资金方怎么分工；C 端套餐款如何「实时清分」、收入如何摊销、退款与站点合伙人如何切分。

## 业务设定

### 一句话

默认架构：**运营商子商户收款**，支付成功立刻拆成「平台技术服务费 1% + 运营商约 99%」；平台不抽运营分成，也不用自有账户代收再手工分钱。包月收入另按服务日摊销做报表；提现须申请并由平台审核。跨运营商柜电费走保证金日清，见换电结算专文。

### 角色分工

| 角色 | 投入 / 产出 |
|------|-------------|
| 运营商 | 自有或租赁柜电；运维与用户服务；渠道批发；**收款主体** |
| 渠道商 | 向运营商采购人天等；在签约模式内服务骑手 |
| 平台（品牌方） | 物联网、用户端、运营后台、清分规则与对账；收 **1% 技术服务费**；可选 SaaS 对公另结 |
| 资金方 | 出租柜电；管租赁与租金 |

硬件投入在运营商（租赁时产权可在资金方）。各方按设备归属隔离订单与流水。

### C 端清分（已定）

1. 骑手支付成功 → **实时清分**：平台 1%、运营商净额入运营商子商户（状态「已清分」）。  
2. **提现** ≠ 清分：须运营商申请、平台审核后打到绑定账户（见 [运营商提现规则.md](./运营商提现规则.md)）。  
3. **退款**：由**运营商子商户**原路退；**平台已收 1% 不退**；若已提现导致余额不够 → 标记须垫付。  
4. 设备租赁白名单套餐款进**渠道子商户**，不适用运营商提现审核。

### 双台账（不要混在一个列表）

| 台账 | 何时动 | 后台大概在哪 |
|------|--------|--------------|
| 清分（钱） | 支付成功 / 退款冲正 | 我的流水 → 清分明细；另有资金实收、提现申请 |
| 收入（账） | 包月按日摊销，或次卡当笔 | 内部报表；归属**运营商主体**，**不按站点**分摊收入 |

包月推荐：实付按服务天数每日确认一份；中途退款停止后续确认并冲减相应收入。站点只用繁忙度等评估，不用收入归因。

### 退款类型（经营侧）

| 类型 | 典型 | 处理要点 |
|------|------|----------|
| 全额 | 未使用、重大故障等 | 终止服务；按政策冲已确认 |
| 部分 | 提前解约退剩余 | 剩余不再确认；冲减与应退对齐 |
| 仅退差价 | 降级等 | 冲差额对应部分 |

细则与冷静期见 [个人套餐定价与退款.md](./个人套餐定价与退款.md)。

### 平台 1% 两种触发

| 场景 | 何时 |
|------|------|
| 个人 / 链接购套餐等 C 端支付 | 支付成功，按实付 |
| 渠道人天确认消耗 | 确认消耗，按平台标准人天价向额度售卖方计提 |

渠道 B2B 批发款采购到账即是运营商收入，**不会**因骑手再换一次电向运营商二次打款。

### 监管红线（必读）

- 禁止平台自建资金池、先代收再手工私分（二清风险）。  
- 资金进持牌支付/存管；平台做规则与对账。  
- **收款主体**=运营商二级商户；**分账接收方**=平台企业商户（收 1%）。  
- 进件、开户、清分、提现含义不同：清分是商户号之间拆账；提现是商户号到银行卡。

### 站点合伙人

运营商按**站点**绑场地合伙人、设分润比例；同一人可在多站拿不同比例。支付清分仍只有「平台 1% + 运营商 99%」；合伙人份额默认从运营商台账切出后**代付/对公**，一般不进微信/支付宝分账接收方。合计比例 ≤ 99%；变更立即生效并留痕，不回溯历史。详见 [站点合伙人.md](./站点合伙人.md)。

### 平台营销（二期）

立减券 + 购时锁定运营商；款进该运营商子商户；与架构 B 同一主干。见 [平台营销-PRD.md](./平台营销-PRD.md)。

### 一期提醒

真实通道联调时须建设监管冻结/释放与账务勾稽；原型可用 Mock 状态演示。

## 实现附录（开发用）

> 业务读者可跳过。公式、术语、通道选型参考、决策索引集中于此。

### A. 清分与收入公式（摘要）

```
支付成功：平台 += P×1%；运营商子商户 += P×99% − 通道手续费（按通道规则）
包月每日确认：P/D（自然日或合同约定）
退款：运营商子商户原路退 R；平台 1% 不退；清分与收入冲正
```

合伙人（从已确认可分配收入 B，站点维度）：

```
platform = round(B×1%, 3)   // 若该层仍计；与支付时 1% 台账口径以专文为准
partner_i = round(B×R_i/100, 3)
operator = B − platform − Σ partner_i   // 尾差归运营商
```

不计入合伙人基数：渠道人天、设备租赁白名单、跨网费、B 端 1% 计提。

### B. 术语对照

| 术语 | 含义 |
|------|------|
| 进件 | 向支付机构提交资料申请商户 |
| 开户 | 进件通过后开通商户号与结算卡 |
| 清分 | 收款商户待分账余额拆到多方 |
| 提现 | 商户可提余额到银行卡 |

### C. 对账字段（摘要）

subscription_id、payment_id、service_start/end、recognition_date、recognized_amount、platform_fee、op_amount、refund_*、settlement_status（已清分/已提现/须垫付/冻结）等。

### D. 数值示例

P=300、D=30：支付清分平台 3 + 运营商 297；日确认 10；中途退 120 则原路退并冲正；已提现后余额不足标须垫付。

### E. 通道选型（参考，非报价承诺）

首期优先微信+支付宝子商户/直付通 + 实时分账与回退；规模化可评估持牌聚合或银行存管组合。招标须确认：子商户收款、支付成功实时分账、收款方原路退、企业商户、已提现后退款垫付/回退等。费率以签约报价为准。详细 RFQ 问题清单可复用历史评审材料，本文不展开厂商宣传对比。
