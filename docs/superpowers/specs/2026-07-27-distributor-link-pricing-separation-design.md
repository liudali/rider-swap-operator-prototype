# 分销商-链接类 · 授权套餐入口收拢 + 命名对齐

## 目标

1. **链接类**（原「卡差价」）渠道商的授权套餐 / 专享价 / 佣金，从「签约渠道」资料编辑页移除，**仅**在「平台设置 → 渠道分销价」维护。
2. 全平台命名对齐：结算模式与角色类型文案见下表。

## 已确认方案

| 项 | 决策 |
|----|------|
| 授权套餐入口 | 方案 1：纯移除；新建静默保存、零授权 SKU；灰字提示去分销价页 |
| 新建后引导 | **A**：不跳转、不强制配价 |
| 角色类型文案 | **B**：改类型名；能力模块名（渠道分销价等）不强制改 |
| 结算模式 | `卡差价` → **`链接类`**；`激活码` 结算模式名不变 |
| 角色类型 | 链接类渠道商 → **分销商-链接类**；激活码渠道商 → **分销商-激活码** |

## 命名对照

| 维度 | 旧 | 新 |

| 角色/类型标签 | 渠道商·激活码 | **分销商-激活码** |

## 职责边界

| 入口 | 负责 | 不负责 |
|------|------|--------|
| 渠道管理 → 签约渠道 | 主体资料、结算模式、合同期、佣金及时到付 | 授权 SKU、正式价/专享价/佣金 |
| 平台设置 → 渠道分销价 | 按渠道×SKU 新增/编辑/停用 | 签约档案、即时到付开关 |

## 运营商配置生命周期

```text
新建签约（链接类）
  → 已签约 · 零授权 SKU（待配价）
  → 渠道分销价新增渠道×SKU（启用）
  → 可售（渠道可生成链接）
  → 调价 / 停用 SKU（对新单生效）
  → 合同停用 / 主体已停用
```

| 阶段 | 列表表现 | 渠道商侧 |
|------|----------|----------|
| 待配价 | 合作内容：`待在渠道分销价配置`；授权 0 SKU | 套餐与链接空态 |
| 可售 | 授权 N 个 SKU + 价摘要 | 可生成链接 |
| SKU 停用 | 该 SKU 不可出链 | 可选列表不含停用 SKU |

## 枚举

| 字段 | 枚举 |
|------|------|
| `settlement_mode` | `人天池` / `链接类` / `设备租赁` / `激活码` |
| 渠道商 `status` | `在营` / `已停用` |
| 合同 `status` | `启用` / `停用` |
| 即时到付 | 关闭·线下 / 开启·即时 |
| 分销价行 `status` | `启用` / `停用` |

约束：`channel_price ≤ official_price`。

## 签约弹窗（链接类）

1. 删除「授权套餐」价表；保存不再读写 `channelSalePackages`。
2. 保留「佣金及时到付」。
3. 灰字：`授权套餐与专享价请在「平台设置 → 渠道分销价」维护。`
4. 弹窗宽度与其他人天池一致即可。

## 原型改动点

- `openChannelPartnerForm` / `saveChannelPartnerForm`：移除价表与 `applyCardSkuPricingFromForm`。
- `settlementMode === "卡差价"` → `"链接类"`（Mock + 分支全量替换）。
- 新增 `channelTypeLabel(mode)`：链接类→分销商-链接类；激活码→分销商-激活码；其余保持「渠道商 · {mode}」或既有写法。
- `contractPricingCell` / `contractTermsCell`：0 SKU 时展示待配价文案。

## 文档同步

- `渠道结算模式规则.md` §3：配置入口仅分销价；步骤 2–3 改至分销价页；结算模式名「链接类」。
- `PRD.md` §2.3 / §5.3.2：命名与入口。
- `acceptance-criteria.md`：签约无授权价表；分销价为唯一维护口。
- `角色与功能清单.md`：角色名分销商-链接类 / 分销商-激活码。

## Non-goals

- 不做保存后跳转分销价。
- 不改即时到付规则与 C 端购卡链路。
- 不强制改「渠道分销价」Tab 名称。
- 不改人天池 / 设备租赁命名。

## 验证

1. 链接类新增/编辑弹窗无授权套餐表；有灰字提示；即时到付仍在。
2. 新建链接类渠道默认 0 SKU；列表显示待配价。
3. 渠道分销价可新增/编辑该渠道 SKU。
4. UI 结算模式列为「链接类」；角色类型为「分销商-链接类」/「分销商-激活码」。
5. 无残留用户可见「卡差价」结算模式文案（历史文档变更记录除外）。
