# 原型右侧文档搜索悬浮框设计

| 项 | 内容 |
|----|------|
| 日期 | 2026-07-28 |
| 阶段 | 原型工具增强（MVP） |
| 决策 | decision-087、decision-091 |
| 状态 | 已确认 · 已实现（原型） |

## 目标

文档数量多、规则分散，不熟悉的人只能逐个翻文档页。在**运营商后台原型**右侧增加可收起悬浮框：全文检索产品文档，并在框内预览整篇 md；进入模块/页面时**自动带出当前页关键词并预匹配**，降低「对照页面找规则」成本。

## 已确认范围

| 项 | 结论 |
|----|------|
| 主场景 | A · 边看原型边搜规则 |
| 点结果 | 框内完整预览整篇 md |
| 索引范围 | 甲 · `docs/*.md` 产品文档全集（与文档页同源） |
| 实现路径 | 方案一 · 运行时 fetch md + 客户端检索 |
| 额外 | 打开模块/页面 → 页面释义 + **本页关键设定摘要卡**（方案一）；文档列表降为溯源 |
| 在线 AI | 不做（Pages 静态站无模型；方案三需另接网关） |

## Non-goals

- 不索引 `decisions/`、`specs/`
- 不做服务端 / 向量检索
- 不做骑手端悬浮框（本期）
- 面板内不做 mermaid 渲染（降级为代码块）
- **不**在每次切页时强制自动展开面板（避免打断操作）

---

## 1. 交互与布局

### 形态

- 固定右侧；`z-index` 高于主内容，**低于**现有抽屉/弹窗。
- **收起**：右侧竖条「文档」；若当前页有预匹配命中，竖条可显示小数字角标（命中文档数，上限 9+）。
- **展开**：宽约 400–440px，遮盖右侧内容区，**不挤压**整页栅格。
- 仅挂 `prototype/index.html`（运营商后台）。

### 面板结构

1. 顶栏：「搜文档」+ 收起
2. **当前页释义** → **来源与前置**（MVP：人天池 + 订单/退款）→ **本页关键设定摘要卡** → 相关文档溯源（折叠）
3. 搜索框：占位「搜索产品规则，如：押金、退款、额度池」；手改后仍走全文检索列表
4. 结果 / 正文二态
   - **默认（未手改）**：3～7 条规则摘要（一句 + 出处）；可展开原文；点出处进匹配段
   - **搜**：命中列表（文档名 + 摘要一行，关键词高亮）
   - **读（有关键词）**：默认只展示命中段落/小节（高亮），可切「查看全文」；目录点入仍全文
   - **读（无关键词）**：整篇 md；顶条：文档名 ·「← 返回」·「新标签打开」
5. 空搜（无上下文且无输入）：按 `DOC_GROUPS` 分组目录

### 状态

| 态 | 表现 |
|----|------|
| 索引加载中 | 「正在加载文档索引…」 |
| 无命中 | 「未找到，试试押金 / 渠道结算」 |
| fetch 失败 | 「文档加载失败（请用本地 http 打开，勿双击 html）」 |

## 2. 搜索与数据流

### 文档清单

- 抽出 `prototype/js/doc-catalog.js`：`DOC_GROUPS` + `docFileUrl()`，文档页与悬浮框共用，避免双轨。

### 加载

- 首次展开（或首次需要预匹配角标时）并行 fetch 各篇 md。
- 会话内存缓存；单篇失败跳过并记日志，不堵整库。
- 路径：本地 `docs/md/`；Pages 下与现网一致（`documentation/md/` 或 sync 后的镜像路径，实现时与 `navDocsLink` 对齐）。

### 用户主动检索

- 匹配：文件名、label、正文；不区分大小写。
- 多词空格分隔 → **AND**。
- 排序：标题/文件名命中优先 → 命中次数 → 文档组顺序。
- 摘要：首条命中前后约 40 字。
- debounce ~200ms。

### 打开全文

- 框内 marked 渲染整篇。
- 「新标签打开」→ `docs/index.html?file=<encodeURIComponent(filename)>`（文档页需支持该深链）。

## 3. 进页自动关键词与预匹配（新增）

### 触发

- 路由变化：顶层 `view` 变化，或页内 Tab 变化导致有效页面键变化（如 `orderService` + `userDeposit` → 有效键 `orderUserDeposit`）。
- 与现有 `pageTitle` / `NAV_LABEL` / Tab 解析对齐，**不**对 DOM 做 NLP 抽词。

### 关键词来源（确定性，按优先级合并去重）

1. **页面标题**：`NAV_LABEL[viewKey]` 或 `meta[viewKey][0]`（如「用户押金」）
2. **别名表** `VIEW_DOC_KEYWORDS[viewKey]`：人工维护的短词列表（如用户押金 → `押金`、`退押`、`实付`）；无配置则仅用标题
3. **可选**：从 `meta` 副标题拆常见业务词（仅当有别名表缺失时的弱补充；实现以 1+2 为主，副标题分词可二期）

### 预匹配行为

| 场景 | 行为 |
|------|------|
| 面板**收起** | 后台算命中数 → 更新竖条角标；**不**自动弹开 |
| 面板**展开**且搜索框未被用户手动改过 | 展示**当前页业务设定推荐**（见下）；输入框仅填页面名 |
| 面板展开且用户已手改查询 | **不覆盖**输入；全文 AND 检索；上下文条提示「可恢复当前页推荐」 |
| 用户点「清除」/「恢复当前页推荐」 | 清空手改标记，重新套用当前页推荐 |

### 预匹配排序（业务设定优先）

1. **`VIEW_DOC_PREFER[viewKey]`** 置顶（规则真源，标「推荐」）
2. 补充命中：标题命中或业务分组（业务与结算 / 产品需求 / 结构与清单）且非弱相关
3. **不参与关键词预匹配**：产品/原型变更记录、验收标准、最小埋点、设计评审、会议对齐决议、需求评审决策、税筹参考与税收待讨论、竞品功能/借鉴/拍板、任务·订单审计/设备告警/美团 SDK、待考虑内容等（`CONTEXT_DEMOTE_FILES`）；文档目录仍可手动打开
4. 手动搜索不受上述过滤，仍全文 AND 检索

> 2026-07-28：验收标准、税筹、三篇任务专文等从预匹配范围移除。

### 示例

进入「订单与服务 → 用户押金」：

- 关键词：`用户押金` + 别名 `押金`、`退押`
- 预匹配预期命中：《骑手电池押金》《个人套餐定价与退款》《acceptance-criteria》等含押金规则的文档
- 收起态角标显示命中篇数；展开即见列表，可点开全文

## 3.5 来源与前置（decision-091）

### 落位

独立第三节，介于「当前页是什么」与「本页关键设定」之间；手改搜索后隐藏（与释义块一致）。

### 数据

`VIEW_PAGE_LINEAGE[viewKey]`：

| 字段 | 含义 |
|------|------|
| `upstream` | 前置一句：本页在流程中的位置 |
| `sources` | 数据来源一句 |
| `downstream` | 下游一句 |
| `links` | `{ key: viewKey, label }` 可跳转相关原型页 |

MVP 覆盖：`dayPool_*` 主 Tab + 订单/退款六页；**2026-07-28 全量**：与 `VIEW_PAGE_MEANING` 全部 viewKey 对齐。

### 跳转

面板按钮 `data-doc-nav="{viewKey}"` → `window.navigateDocPanelView(viewKey)`（`app.js`），与 `resolveDocSearchViewKey` Tab 解析对齐。

与规则卡「出处」不同：出处进 md 溯源；相关页进原型导航。

## 4. 工程落点

| 文件 | 作用 |
|------|------|
| `prototype/js/doc-catalog.js` | `DOC_GROUPS`、URL、`VIEW_PAGE_LINEAGE`、可选 `VIEW_DOC_KEYWORDS` |

| `prototype/docs/index.html` | 改用 catalog；支持 `?file=` |

`sync-pages.sh` 照常镜像；无额外构建步骤。

## 5. 验收

1. 右侧「文档」竖条可展开/收起。
2. 搜「押金」命中《骑手电池押金》等；摘要高亮。
3. 点结果 → 框内整篇可读；返回结果；新标签 `?file=` 打开同篇。
4. 空搜（无上下文）显示分组目录；无命中有空态。
5. 抽屉打开时面板不盖住抽屉。
6. **进「用户押金」页**：收起态出现角标；展开后自动预匹配且上下文条为「用户押金」；手改搜索词后切页不覆盖；点「恢复当前页推荐」可恢复。
7. 文档清单与独立文档页一致（同源 `doc-catalog.js`）。
8. **进「额度分配」或「退款管理」**：展开面板见「来源与前置」三节文案；点「额度池列表」等按钮可跳转对应 Tab。

## 6. 风险与边界

- 首次索引耗时：可接受；角标在索引未完成前不显示或显示加载点。
- 别名表不全：仅标题仍可搜；后续按高频页补 `VIEW_DOC_KEYWORDS`。
- 强制弹开会打断操作 → 明确 Non-goal。

## 大师交叉（摘要）

- **俞军**：新体验 = 当前页相关规则秒达；替换成本低于逐个翻目录。
- **乔布斯**：只做搜+预览+页上下文，不做第二套知识库。
- **失效条件**：catalog 与 docs 真源长期双轨 → 必须共用 `doc-catalog.js`。
