# 渠道设备租赁 · 白名单套餐拆页 + 电池型号同步

| 项 | 内容 |
|----|------|
| 日期 | 2026-07-28 |
| 阶段 | 二期原型（设备租赁） |
| 决策 | decision-089 |
| 状态 | 已确认 · 已实现（原型） |
| 关联 | decision-090（SKU 对齐个人套餐） |

## 目标

1. 将渠道「白名单套餐」页内两模块拆成两个二级菜单页，降低配置与流水混读。
2. 将 decision-085/088 的「套餐 ↔ 电池型号」口径同步到白名单套餐（此前未覆盖）。

## 已确认范围

| 项 | 结论 |
|----|------|
| 开关 | **不做**白名单总开关 |
| 拆页 | 方案 A：侧栏并列两项 |
| 型号 | SKU 行内挂 `batteryModel`；枚举取自平台启用字典 |
| 通兑 | **无一单通兑**；权益绑定购买时型号 |

## Non-goals

- 白名单能力启停开关
- 改收款/分账规则、骑手端购套餐交互深改（仅 Mock/展示对齐型号即可）
- 运营商代设白名单 C 端价

---

## 1. 信息架构

侧栏（`CH-RENT` 设备租赁），原「白名单套餐」拆为：

| 路由 key | 菜单名 | 内容 |
|----------|--------|------|
| `leasePkgPricing` | **白名单套餐** | 仅 SKU 定价表 + 编辑价格 |
| `leasePkgOrders` | **白名单订单** | 仅购套餐订单表 |

菜单位置：紧挨原「白名单套餐」处；其后仍为收款账户、月租账单等。  
权限：两项均挂既有 `lease_pkg.view`（或等价映射）。

---

## 2. 电池型号（对齐 decision-085/088）

### 唯一键（渠道白名单）

`渠道 × 电池型号 × 套餐名（或 SKU id）`

（设备租赁无「城市底价」维，不引入城市。）

### 定价页列表列

SKU → **电池型号** → 套餐名 → 零售价 → 有效期 → 状态

### 编辑表单

- 必选 **电池型号**（下拉 = `BATTERY_MODEL_OPTIONS` 启用项）
- 编辑时：SKU id 只读；**型号可改**（演示）；若改后与同渠同型号同套餐名冲突则拦截
- 文案提示：套餐权益仅支持该型号电池换电

### Mock

| SKU | 型号 | 套餐 | 价 |
|-----|------|------|-----|
| LP-30 | `48V30Ah` | 30天畅换 · 白名单专享 | ¥299 |
| LP-30B | `60V30Ah` | 30天畅换 · 白名单专享 | ¥349 |
| LP-7 | `48V30Ah` | 7天体验套餐 | ¥89 |

### 订单页

增列 **电池型号**（下单快照）；既有订单 Mock 补 `batteryModel`。

### 引用计数

`batteryModelUsageCount` 计入 `channelLeasePkgSkus`（停用型号时引用可见）。

## 3. 页面细则

### 白名单套餐（定价）

- Banner：仅白名单可购；款进本渠道子商户（不变）
- 空态：暂无上架套餐
- 操作：表格行内「编辑」（替代原页级单 SKU 演示按钮），以支持多型号多行

### 白名单订单

- Banner：收款方 = 本渠道子商户
- 列：订单 / 用户 / 套餐 / **电池型号** / 实付 / 子商户 / 支付时间
- 空态：暂无购套餐订单

---

## 4. 验证

1. 侧栏两项可独立进入；定价页无订单表，订单页无定价表。
2. 定价列表有电池型号列；Mock 同名套餐可对 48V/60V 各一行。
3. 编辑可选启用型号；保存后列表刷新。
4. 订单行展示购买时型号。
5. 平台型号「引用数」含白名单 SKU。
