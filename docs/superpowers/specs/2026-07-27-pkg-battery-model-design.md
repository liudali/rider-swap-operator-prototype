# 个人套餐价 · 电池型号维度

## 目标

个人套餐 SKU 增加 **电池型号**；不同型号下的套餐、有效期、零售价、状态相互独立。套餐必须与型号绑定，**无一单通兑全型号**。

## 已确认

| 项 | 决策 |
|----|------|
| 结构 | 方案 1：SKU 行内挂型号 |
| 型号枚举 | A：规格串，与台账对齐 |
| 无套餐的型号 | **不展示该型号**（不对用户露出空型号） |
| 通兑 | **不存在**；权益绑定购买时的型号 |

## 唯一键

`运营商 × 城市 × 电池型号 × 套餐名`

## 枚举

| 字段 | 值 |
|------|-----|
| `battery_model` | `48V20Ah` / `48V30Ah` / `60V30Ah` |
| 状态 | `生效` / `停用` |

## 运营商 · 个人套餐价（城市底价）

- 列表列：城市 → **电池型号** → 套餐 → 有效期 → 零售价 → 状态 → 更新时间 → 操作
- 筛选（可选）：城市、电池型号、状态
- 新增：必选型号；冲突拦截「该型号下已存在此套餐」
- 编辑：城市 / 型号 / 套餐名只读；可改零售价、状态（及有效期若可编）
- Mock：现有行默认 `48V30Ah`；另加同城同套餐不同型号演示行

## 骑手购套餐

1. 仅展示「有 ≥1 条生效 SKU」的型号；**无可用套餐的型号不出现在型号选择/列表中**。
2. 选型号后只看该型号下生效套餐。
3. 下单快照写入 `battery_model`；换电仅匹配同型号电池。
4. 型号不匹配：拦截「当前套餐仅支持 {型号}」。

## 渠道分销价

本期：关联个人套餐底价行时 **只读继承型号**，不在分销价页单独改型号。

## Non-goals

- 不建型号字典管理页
- 不做一单通兑
- 不深改价格分区二期（区价行后续同样应带型号；本期 Mock 继承城市底价型号即可）

## 验证

1. 列表有电池型号列；唯一键冲突不可保存。
2. 同城「包月30天」可对 48V30Ah / 60V30Ah 各一行、价不同。
3. 某型号无生效套餐时，购套餐入口不出现该型号。
4. 订单/权益展示绑定型号。
